AWS Backup:RDS が論理的エアギャップ vault に対応

AWS Backup の論理的エアギャップ vault が Amazon RDS の DB インスタンスに対応し、改ざんできない隔離されたバックアップを作れます。

最終更新:2026-11-18

1. 発表の内容#

論理的エアギャップ vault は、AWS Backup でバックアップを入れる特別な保管場所(vault)です。ロックされたままの変更できないバックアップを、元のアカウントから論理的に隔離して保管します。誤操作やランサムウェア、アカウントの乗っ取りでバックアップごと消されることを防げます。以前から対応していたリソースに加え、今回 RDS の DB インスタンスも対象になりました。

バックアッププランで、同じリージョンの論理的エアギャップ vault をコピー先に指定します。vault は RAM で他のアカウントと共有でき、共有先から直接リストアも始められるので、障害時の復旧が早くなります。アカウントの侵害に備え、マルチパーティ承認も使えます。

説明の中心 成功・推奨・正常 利用者・外部・送信元 その他の構成要素

何がうれしいか
ランサムウェアやアカウントの侵害からデータベースのバックアップを守り、安全に復旧できます。
試験・実務への影響
信頼性・事業継続では、バックアップの保護(Vault Lock、クロスアカウント、クロスリージョン)が出題されます。RDS も論理的エアギャップ vault で守れると押さえておきましょう。
