STS:実行時に権限を絞り込む GetScopedCredentials

手持ちの一時的な認証情報から、権限や有効期間をさらに絞った認証情報を作れる API が加わりました。

最終更新:2026-11-21

1. 発表の内容#

STS(Security Token Service)は、有効期限のある一時的な認証情報を発行するサービスです。新しい API「GetScopedCredentials」は、いま使っている一時的な認証情報を元に、権限、有効期間、またはその両方を狭めた認証情報を作ります。呼び出した人の ID は引き継がれ、権限と期間は元より広くなりません(狭める方向にだけ変えられます)。

AI エージェントやサブエージェント、個々のワークロードに、必要な権限だけを持たせた認証情報を渡す用途を想定しています。この API を使えるかどうかは IAM ポリシーで制御でき、呼び出しは CloudTrail に記録されます。

説明の中心 成功・推奨・正常 利用者・外部・送信元

何がうれしいか
実行時に、最小権限の認証情報を手軽に作れます。IAM ロールを権限の組み合わせごとに増やさずに済みます。
試験・実務への影響
「最小権限の原則」を実行時に適用する手段の1つです。権限を広げることはできない点が試験で問われやすい考え方です。
