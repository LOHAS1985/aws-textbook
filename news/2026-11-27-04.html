Lambda:durable functions から MicroVM を順に動かせる拡張(開発者プレビュー)

Lambda durable functions から Lambda MicroVM の起動と実行をまとめて管理できる拡張が、開発者プレビューとして始まりました。

最終更新:2026-11-27

1. 発表の内容#

Lambda durable functions は、途中経過を保存(チェックポイント)しながら、最長1年かかる複数ステップの処理を再試行つきで動かせる仕組みです。Lambda MicroVM は、仮想マシン並みの隔離と素早い起動ができる実行環境で、利用者や AI が作ったコードを安全に動かす用途に向きます。

今回の拡張で、durable function が MicroVM の起動・終了を管理し、各タスクを耐久性のある操作として実行できます。失敗したタスクの再試行や進捗の保存も自動です。1つの関数が複数の MicroVM を並列に動かすこともでき、SQS や EventBridge から起動できます。TypeScript と Python の SDK が対象で、プレビュー版なので本番では使えません。
