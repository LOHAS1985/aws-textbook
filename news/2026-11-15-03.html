Batch:EKS のジョブで Linux capabilities・seccomp・Pod 単位の設定に対応

Batch の EKS 向けジョブ定義で、Kubernetes のセキュリティコンテキストの設定項目が増えました。

最終更新:2026-11-15

1. 発表の内容#

AWS Batch の EKS 向けジョブ定義で、Linux capabilities と seccomp プロファイル、Pod 全体の設定(fsGroup など)を指定できるようになり、制限の厳しい Pod Security Standards の restricted プロファイルを使うクラスターでも、必要最小限の権限でジョブを動かせます。
