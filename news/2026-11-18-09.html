Security Hub:Google Cloud のリソースも監視

Security Hub が Google Cloud のリソースを監視できるようになりました。

最終更新:2026-11-18

1. 発表の内容#

Google Cloud の VM、コンテナーイメージ、Cloud Run 関数、ID を自動で見つけ、設定の不備や脆弱性を検出します。AWS・Azure の結果と同じ画面で扱えます。連携を作ると、30日間の無料トライアルがあります。
