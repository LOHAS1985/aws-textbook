2. 学習ロードマップ

ステップ1から順に読み進め、各ステップの最後に対応する分野の問題を解きます。分野の配点ではなく、AWSの前提からデータの流れ(取り込み、保存、運用、保護)に沿って並べています。

ステップ1 AWSの前提

対象のタスク: 4.1(認証)、2.1(データストアの選択)の前提。目安は1週間です。

  • 責任共有モデル
  • リージョンとアベイラビリティーゾーン
  • AWS IAMとポリシーの評価ロジック
  • IAMロールと一時的な認証情報
  • Amazon S3(データレイクの土台)

ステップ2 データの取り込みと変換(分野1・34%)

対象のタスク: 1.1〜1.4(スキル1.1.1〜1.4.11)。取り込みの方式、変換、ワークフロー、プログラミングを学びます。

  • 基礎:データパイプラインの基礎
  • 取り込み(1.1):Amazon Kinesis・Amazon Data Firehose・Amazon MSK・AWS DMS・Amazon AppFlow・Amazon DynamoDB(ストリーム)
  • 変換(1.2):AWS Glue・Amazon EMR・Amazon Managed Service for Apache Flink・AWS Lambda・AWS Batch・Amazon API Gateway(データのAPI)
  • オーケストレーション(1.3):AWS Step Functions・Amazon MWAA・Amazon EventBridge・Amazon SQS・Amazon SNS
  • プログラミングとIaC(1.4):AWS CloudFormation・AWS CDK・AWS SAM・メッセージングサービスの選び方

問題: 問題集の分野1を解く。

ステップ3 データストアの管理(分野2・26%)

対象のタスク: 2.1〜2.4(スキル2.1.1〜2.4.6)。保存先の選び方、カタログ、保存期間、スキーマの変化を学びます。

  • 選び方:データストアの選び方・ストレージの種類・ベクトル検索
  • データレイク・形式:AWS Lake Formation・オープンテーブル形式・Amazon Redshift
  • データストア:Amazon DynamoDB・Amazon RDS・Amazon Aurora・Amazon DocumentDB・Amazon Keyspaces・Amazon Neptune・Amazon MemoryDB
  • ライフサイクル:Amazon S3のライフサイクルルールとバージョニング、AWS Backup
  • カタログ・系譜:AWS GlueのData Catalog、Amazon SageMaker Unified Studio

問題: 問題集の分野2を解く。

ステップ4 データ運用とサポート(分野3・22%)

対象のタスク: 3.1〜3.4(スキル3.1.1〜3.4.5)。処理の自動化、分析、監視、データ品質を学びます。

  • 分析とクエリ:Amazon Athena・Amazon Quick・Amazon Redshift
  • データの準備と品質:AWS Glue DataBrew・データ品質
  • 監視と保守:監視・記録のサービスの選び方・Amazon CloudWatch・CloudWatchアラームの状態と評価・AWS CloudTrail
  • 自動化:イベント駆動の自動修復

問題: 問題集の分野3を解く。

ステップ5 セキュリティとガバナンス(分野4・18%)

対象のタスク: 4.1〜4.5(スキル4.1.1〜4.5.7)。権限、暗号化、監査、プライバシーを学びます。

  • 認証と認可:AWS IAM・AWS IAM Identity Center・iam:PassRole
  • 認証情報と暗号化:AWS Secrets Manager・機密情報・設定値の保存先の選び方・AWS KMS・保存時の暗号化と転送時の暗号化
  • プライバシーとガバナンス:Amazon Macie・データガバナンス・AWS Data Exchange
  • 監査:AWS CloudTrail・AWS Config・セキュリティ検出のサービスの選び方

問題: 問題集の分野4を解く。

ステップ6 総合演習

問題集を分野の配分どおりに解き直し、間違えた問題は本文のリンク先で確認します。最後に、DEA-C01の学習範囲の一覧で、学んでいない項目がないかを確かめます。

3. 参考書の使い方

このページの後半にある「参考書」は、上のロードマップで参照しているページを、ステップの順番どおりに並べたものです。印刷やPDFで保存すれば、紙の参考書として使えます。ロードマップのリンクは、それぞれのページに移動します。
