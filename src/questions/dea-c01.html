試験形式を想定して全問をランダムに解くか、復習する問題を選んで解いてください。「2つ選択」とある問題は、要件を満たす選択肢を2つ選びます。採点すると正解と解説が表示され、成績と間違えた問題はこのブラウザーに保存されます。

出題分野はAWS公式のDEA-C01試験ガイドに基づいています。JavaScriptが無効な場合は、各問題の「答えと解説を確認」を開いて答え合わせができます。

分野1 データ取り込み・変換 (34%)

問1

販売システムはオンプレミスのリレーショナルデータベースで稼働し、AWSへの切り替えまで数日間は更新が続きます。分析チームは移行後すぐに、Amazon S3のデータレイクで最新データを利用したいと考えています。一方、アプリケーションの改修や独自のログ転送処理は避ける必要があります。初期データを移した後も更新を追従させる方法はどれですか。

最も適切な方法を1つ選んでください。
答えと解説を確認

正解: A

AWS DMSのフルロードとCDCを組み合わせると、既存データを転送した後もデータベースの変更を継続して複製できます。S3ターゲットにすれば、後続の分析パイプラインへデータを渡せます。

  • B: Glueクローラーはスキーマの検出とカタログ登録に使う機能で、データベースの変更を複製しません。
  • C: DataSyncはファイル転送向けであり、データベースのトランザクションログをCDCとして処理しません。
  • D: フルロードだけでは、その後に発生する更新がデータレイクへ反映されません。

AWS DMS / AWS Glue / AWS DataSync

問2

注文イベントを複数の分析アプリケーションへ低レイテンシーで配信します。各アプリケーションは同じ全イベントをそれぞれ独立して読み取り、1つのアプリケーションの読み取り負荷が他に影響しない構成が必要です。また、障害時には直近48時間のイベントを再処理できるようにしたいと考えています。適切な構成はどれですか。

最も適切な方法を1つ選んでください。
答えと解説を確認

正解: B

Kinesis Data Streamsは複数のコンシューマーが同じストリームを読み取れるため、各アプリケーションが独立して処理できます。保持期間を要件以上に設定すれば、保持中のレコードを再処理できます。拡張ファンアウトはコンシューマーごとに読み取りスループットを分けます。

  • A: Data Firehoseはバッファリングして送信先へデータを配信するサービスで、各アプリケーションが読み取り位置を管理するストリームではありません。
  • C: SQSの1つのキューは、通常、複数のコンシューマーにメッセージを分配します。同じ全メッセージを各アプリケーションへ独立して配る要件には合いません。
  • D: EventBridgeはイベントのルーティングに適していますが、ストリームの保持期間と読み取り位置を使った再処理の要件には合いません。

Amazon Kinesis / Amazon Data Firehose / Amazon SQS / Amazon EventBridge

問3

データレイクのAmazon S3バケットには、Parquet形式の日次ファイルが追加されます。AWS Glueジョブはスケジュール実行され、正常終了した入力を次回に再処理すると重複データが発生するため、新しく追加されたファイルを中心に処理したい要件です。ジョブごとに入力データの処理状態を保持し、再実行時の読み直しを抑える機能はどれですか。

最も適切な方法を1つ選んでください。
答えと解説を確認

正解: C

Glueのジョブブックマークは、ジョブのデータソースで処理したデータの状態を保持し、次回実行時に新しいデータを識別するために使います。状態を正しく保存するには、ジョブをブックマーク対応で実装し、正常終了時に状態をコミットします。

  • A: クローラーはスキーマやパーティションの検出に使います。ETLジョブの処理済み状態を管理する機能ではありません。
  • B: パーティション射影はAthenaがパーティション情報を組み立てる方法であり、Glueジョブの処理状態を記録しません。
  • D: DMSのCDCはデータベース変更の複製に使います。S3ファイルを処理した状態の管理には使いません。

分野2 データストア管理 (26%)

問4

マルチテナントのイベント管理テーブルで、特定テナントからの書き込みが全体の大半を占めています。現在はテナントIDだけをパーティションキーにしているため、そのテナントの項目にアクセスが集中してスロットリングが発生します。書き込みを複数のキーに分散しながら、後でそのテナントの指定期間のイベントを検索できる設計はどれですか。

最も適切な設計を1つ選んでください。
答えと解説を確認

正解: A

テナントIDにシャード番号を組み合わせる書き込みシャーディングで、同じテナントの高い書き込み負荷を複数のパーティションキーへ分散できます。ソートキーに時刻を置くと、各シャードで期間を指定したクエリができます。対象テナントの全件を集める場合は、該当シャードへのクエリを並行して実行します。

  • B: テナントIDだけでは負荷の高いテナントの書き込みが同じパーティションキーに集中します。
  • C: 時刻だけでは同じ時間帯の書き込みが集中しやすく、テナント単位の取得にも効率的ではありません。
  • D: UUIDは項目を分散しますが、テナント単位で検索するにはテーブル全体のスキャンが必要になります。

問5

企業の分析チームは、複数年分の売上データをディメンション表とファクト表に分け、結合や集計を行うSQLを繰り返し実行します。複数のBI利用者が同時にダッシュボードを更新するため、分析向けに管理されたデータウェアハウスを使いたいと考えています。アプリケーション側で結合処理を実装せずに要件を満たす保存先はどれですか。

最も適切なサービスを1つ選んでください。
答えと解説を確認

正解: B

Redshiftは、SQLによる集計や複数表の結合を行うデータウェアハウスです。BIツールから接続し、分析向けにモデル化したデータへ繰り返しクエリを実行できます。

  • A: DynamoDBはキーを使った高速な項目アクセスに適したNoSQLデータベースで、多数の表を結合する分析基盤ではありません。
  • C: S3はデータレイクに適した保存先ですが、ファイルを毎回ダウンロードして利用者ごとに結合する方法は、共有データウェアハウスの要件に合いません。
  • D: SQSはメッセージのキューイングと処理の分離に使うサービスで、分析データを長期保存してSQL検索する用途ではありません。

問6

データレイクの分析テーブルを複数のクエリエンジンから参照し、データの追加や更新とクエリを並行して実行します。ファイルを直接置き換える方式では更新中の読み取りに一貫性がなく、列の追加などのスキーマ変更も安全に管理できません。読み手が更新前後の整合したデータを参照できるよう、テーブルのスナップショットとスキーマ進化を扱う方法はどれですか。

最も適切な方法を1つ選んでください。
答えと解説を確認

正解: C

Apache Icebergは、スナップショットやスキーマ進化を扱うオープンテーブル形式です。S3上のテーブルを対応するカタログとクエリエンジンから利用することで、ファイル単位の管理より一貫性のあるテーブル操作ができます。

  • A: CSVファイル自体には、並行更新を調整するテーブルのトランザクション管理やスナップショット機能がありません。
  • B: 定期エクスポートはデータ複製の方法ですが、単一ファイルにするだけではスキーマ進化やテーブルのスナップショット管理を実現しません。
  • D: S3オブジェクトタグは分類や属性付与に使うもので、テーブルの更新履歴やトランザクションログにはなりません。

分野3 データ運用・サポート (22%)

問7

AWS GlueのETL処理では、顧客IDが欠けたレコードや、業務上許容する範囲を外れた金額を出力前に見つける必要があります。データ件数が増えても担当者が毎回目視確認する運用は避け、定義した条件に基づく品質評価とジョブ実行ごとの結果確認を行いたいと考えています。毎回同じ品質基準を適用するために適切な機能はどれですか。

最も適切な機能を1つ選んでください。
答えと解説を確認

正解: A

Glue Data Qualityでは、データ品質ルールを定義し、Glueジョブ内のデータを評価できます。欠損や値の条件をルールとして表現し、実行結果を確認できます。

  • B: MacieはS3の機密データ検出に使います。業務データの欠損や数値範囲を検査する機能ではありません。
  • C: CloudTrailはAWS APIの操作履歴を記録します。ETL出力の各行を品質ルールで評価しません。
  • D: クローラーはスキーマやパーティションを推定します。品質ルールを評価して該当行を除外する機能ではありません。

AWS Glue / Amazon Macie / AWS CloudTrail

問8

複数のAWS Glue ETLジョブを毎晩実行しており、そのうち1つでも失敗した場合は運用チームが早く気付けるよう通知したいと考えています。担当者による画面の定期確認も減らす必要があります。状態を問い合わせる独自コードや、失敗を推測する出力データの検査は避け、ジョブ実行の状態変化をきっかけに通知先へ連携する方法はどれですか。

最も適切な方法を1つ選んでください。
答えと解説を確認

正解: D

Glueはジョブ実行状態の変更イベントをEventBridgeへ送ります。失敗状態に一致するルールを作成し、通知先へルーティングすれば、定期的な状態確認コードを実装せずに失敗を検知できます。

  • A: 定期実行によるポーリングが必要で、状態確認コードも追加するため、要件に合いません。
  • B: CloudTrailはAPI操作の監査に使います。ジョブ状態変更のイベントを直接ルーティングする方法ではありません。
  • C: 出力テーブルの行数だけでは、ジョブの失敗と正常終了を区別できません。クローラーも実行状態の通知機能ではありません。

分野4 データセキュリティ・ガバナンス (18%)

問9

AWS Glueジョブが、カスタマーマネージドKMSキーで暗号化されたAmazon S3オブジェクトを読み取ります。ジョブには専用IAMロールを割り当て、対象バケットの必要なプレフィックスと指定したKMSキーだけを利用できるよう最小権限にします。読み取りと復号を成立させるために必要な設定を2つ選んでください。

要件を満たす選択肢を2つ選んでください。
答えと解説を確認

正解: A、B

S3オブジェクトの読み取りには対象オブジェクトへのs3:GetObjectが必要です。SSE-KMSで暗号化されたオブジェクトを復号するにはkms:Decryptも必要で、IAMポリシーとKMSキーポリシーの両方でロールの利用が許可されている必要があります。

  • C: 全バケット・全キーへのワイルドカード権限は最小権限の要件に反します。
  • D: 長期アクセスキーをスクリプトに保存する方法は避け、Glueジョブに割り当てたIAMロールから一時的な認証情報を使います。

AWS Identity and Access Management / Amazon S3 / AWS KMS

問10

組織では複数のAmazon S3バケットを部門ごとに利用しており、個人情報や認証情報が意図せず保存されていないか定期的に確認する必要があります。バケットへのAPI操作を監査するだけでは要件を満たせません。オブジェクトの内容を調べて機密データを検出し、調査すべき対象を把握したい場合に適したサービスはどれですか。

最も適切なサービスを1つ選んでください。
答えと解説を確認

正解: C

Amazon MacieはS3に保存された機密データを検出し、機密データ検出結果を提供します。個人情報や認証情報を含む可能性があるオブジェクトを特定する用途に適しています。

  • A: Lake Formationはデータレイクのカタログ化やアクセス制御に使います。オブジェクトの内容を調べて機密データを検出するサービスではありません。
  • B: GuardDutyは脅威検出サービスです。S3オブジェクト内の機密データを分類する機能とは異なります。
  • D: CloudTrailはS3の操作履歴を記録できますが、オブジェクトの内容を解析しません。
