1. サービス概要

AWS Snow Familyは、AWS Snowball Edgeなどの物理デバイスを使い、大容量データのオフライン転送やエッジ環境での処理を行うサービス群です。ネットワーク帯域が限られる、接続が不安定、現地でデータを処理する必要がある場合に検討します。

新規顧客はSnowball Edgeを利用できません。2025年11月7日以降は既存顧客向けの提供に限られます。Snowconeは2024年11月12日に提供終了し、既存利用のサポート期間も終了しています。最新の提供状況はAWS Snowデバイスの公式更新情報を確認してください。

2. 主な機能・特徴

データ移行とエッジ処理

  • Snowball Edge Storage Optimizedは、大容量データの物理転送を行う。
  • Snowball Edge Compute Optimizedは、ネットワーク接続が限られた現場でコンピューティング処理を行う。
  • デバイスを注文し、現地でデータをコピーしてAWSへ返送する。AWS側で取り込み後、ジョブの状態を確認する。
  • 既存顧客でデバイスを利用できるかは、アカウント・リージョン・デバイスモデルの提供条件を確認する。

新規構成での代替

ネットワーク経由のファイル転送にはAWS DataSync、物理メディアを使うデータ転送にはAWS Data Transfer Terminal、現場でAWS基盤を動かす場合はAWS Outpostsを検討します。

3. ユースケース

  • ネットワーク帯域が限られた拠点から、大量のデータをAWSへ移す。
  • 接続が断続的な現場でデータを収集・処理する。
  • 既存のSnowball Edge利用環境を把握し、移行計画を立てる。

4. 料金の考え方

ジョブの種類・期間、デバイスの配送、データ転送、AWS側の保存先などが料金に影響します。新規顧客は利用を開始できないため、新規移行ではDataSyncやData Transfer Terminalなどの現行代替の料金を確認します。

5. 関連サービス

  • AWS DataSync:オンラインのファイル・オブジェクト転送
  • Amazon S3:データ移行先のオブジェクトストレージ
  • AWS Direct Connect:専用ネットワーク接続
  • AWS Application Discovery Service:移行前の環境調査
  • 関連する用語:データパイプラインの基礎

6. 試験・実務でのポイント

  • ネットワークが制約される環境でのオフライン転送 → Snowball Edgeの用途を理解する。
  • Snowball Edgeは新規顧客向けに提供されないため、新規構成では現行の代替を選ぶ。
  • Snow Familyの名称があっても、Snowconeなど提供終了済みのデバイスを新規構成に含めない。

7. まとめ

  • Snow Familyは物理デバイスを使うオフライン転送・エッジ処理の選択肢。
  • 新規顧客はSnowball Edgeを利用できないため、AWSの最新案内に沿って代替を選ぶ。
