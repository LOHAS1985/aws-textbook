1. サービス概要

AWS DataSyncは、オンプレミスとAWSの間、またはAWSのストレージサービス間でデータ転送を自動化・高速化するサービスです。

区分対応するストレージ
オンプレミス/自己管理NFS、SMB、HDFS、S3互換のオブジェクトストレージ
AWSS3、EFS、FSx
他クラウドGoogle Cloud Storage、Azure Blob Storageなど

2. 主な機能・特徴

構成要素

  • エージェント:オンプレミス/他クラウドのストレージにアクセスするために配置する。AWSのストレージ間の転送では不要。
  • ロケーション:転送元と転送先の定義
  • タスク:転送ジョブの定義(転送元・転送先・オプション・スケジュールをまとめる)

機能

  • 増分転送:初回は全データ、2回目以降は変更分だけを転送
  • スケジュール実行:最短1時間単位で定期実行
  • 整合性の検証:転送後にチェックサムで検証
  • メタデータの保持:タイムスタンプ・所有者・権限などを引き継ぐ
  • 暗号化:転送中はTLSを使用

ネットワーク接続

  • パブリックエンドポイント:インターネット経由
  • VPCエンドポイント:Direct ConnectやSite-to-Site VPNと組み合わせ、インターネットを経由せずに転送

3. ユースケース

  • オンプレミスのファイルサーバー(NFS/SMB)からS3・EFS・FSxへのデータ移行
  • オンプレミスとAWSの間での定期的なデータ同期(増分転送)
  • リージョン間・ストレージサービス間のデータコピー
  • 他クラウドからAWSへのデータ移行

4. 料金の考え方

転送したデータ量(GB単位)に応じて課金されます。転送先のストレージ料金や、リージョン間・インターネットへのデータ転送料金は別途かかります。

5. 関連サービス

  • Amazon S3/Amazon EFS/Amazon FSx:転送先のAWSストレージ
  • Amazon VPC:VPCエンドポイントでのプライベート転送
  • AWS Backup:転送後のバックアップ管理

6. 試験・実務でのポイント

  • オンプレミスのNFS/SMBからAWSへオンラインでデータ移行・同期 → DataSync。
  • オンプレミスから転送するときはエージェントが必要。AWSストレージ間は不要。
  • インターネットを通さずに転送 → VPCエンドポイント+Direct Connect/VPN。
  • 2回目以降は増分転送、転送後はチェックサムで整合性を検証。

7. まとめ

  • DataSyncはエージェント・ロケーション・タスクで構成されるデータ転送サービス。
  • 増分転送・スケジュール・整合性検証・メタデータ保持に対応する。
