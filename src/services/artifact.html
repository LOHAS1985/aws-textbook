1. サービス概要

AWS Artifactは、AWSのセキュリティ・コンプライアンスに関する書類を、必要なときにダウンロードできるサービスです。ISO・PCI DSS・SOCなどの第三者による監査レポートや認証書類を入手でき、AWSとの契約(BAAなど)の確認・締結もできます。

監査人や規制当局に「AWSの基盤は、この基準を満たしている」と示す証拠として使います。AWS側の証明のためのサービスで、利用者自身の設定の準拠状況を確認するサービスではありません。

2. 主な機能・特徴

機能できること例
Artifact ReportsAWSが受けた監査のレポートや認証書類をダウンロードするSOC 1・SOC 2・SOC 3レポート、ISO 27001などの認証、PCI DSSの準拠証明
Artifact AgreementsAWSとの契約を確認・承諾・終了する。Organizationsの組織全体に対しても結べるBAA(米国の医療情報の取り扱いに関する事業提携契約)、NDA
  • 書類は、コンソールからいつでもオンデマンドでダウンロードできる。機密性の高いレポートは、ダウンロード前にNDA(秘密保持契約)への同意を求められることがある。
  • Organizationsを使っていれば、管理アカウントが組織の契約を結ぶことで、既存・今後のメンバーアカウントすべてが対象になる。
  • AWS Marketplaceで製品を販売する独立系ソフトウェアベンダー(ISV)のセキュリティ・コンプライアンス関連の書類も入手できる。
  • ダウンロードや契約には、IAMでArtifactの権限が必要。日常の操作にはルートユーザーを使わず、IAMユーザーやロールに必要な権限だけを与える。
  • 書類は参考資料にもなり、自社のクラウド構成や内部統制が十分かを評価するときの指針に使える。

3. ユースケース

  • 監査人から「データセンターの物理的なセキュリティや、基盤の認証状況の証拠」を求められたとき、SOCレポートやISO認証を提出する
  • クレジットカード情報を扱うシステムで、AWS側のPCI DSS準拠の証明を提出する
  • 医療情報を扱う前に、BAAを結んで法的な要件を満たす
  • AWSの基盤が満たす基準を調べ、自社の設計や内部統制を評価する

4. 料金の考え方

AWS Artifactのドキュメントと契約は、無料で利用できます。

5. 関連サービス

  • AWS Config:利用者側のリソース設定を記録し、ルールで評価する
  • AWS Security Hub:セキュリティ基準に照らして利用者側の設定をチェックする
  • AWS CloudTrail:操作の記録
  • AWS Organizations:組織全体の契約
  • AWS IAM:Artifactを使う権限の制御
  • 関連する用語:コンプライアンスとAWS Artifact、責任共有モデル

6. 試験・実務でのポイント

  • 監査人にAWSのSOCレポート・PCI DSS・ISOの準拠証明を提出したい → AWS Artifact。
  • AWSとのBAAなどの契約を結ぶ → AWS Artifact(Agreements)。
  • 利用者自身のリソースが基準を満たしているかの継続的な確認 → AWS ConfigやSecurity Hub。Artifactは「AWS側」の証明で、利用者側の設定は確認しない。
  • 書類のダウンロードと契約は無料。
  • 組織全体の契約は、Organizationsの管理アカウントで結ぶ。

7. まとめ

  • AWS Artifactは、AWSの監査レポート・認証書類の入手と、AWSとの契約の締結ができる無料のサービス。
  • AWS側の準拠を示すのはArtifact、利用者側の準拠を確認するのはConfigやSecurity Hub。
