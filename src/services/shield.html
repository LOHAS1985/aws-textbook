1. サービス概要

AWS Shieldは、DDoS攻撃(分散型サービス妨害攻撃)からAWS上のアプリケーションを守るサービスです。DDoS攻撃とは、多数のコンピューターから大量の通信を送りつけて、サービスを使えなくする攻撃です。

無料で全員に適用される Shield Standard と、有料で保護を強化する Shield Advanced の2種類があります。

2. 主な機能・特徴

Shield Standard と Shield Advanced

項目Shield StandardShield Advanced
料金無料(申し込み不要・自動で適用)月額料金(1年契約)+データ転送料
防げる攻撃よくあるネットワーク層・トランスポート層(L3/L4)の攻撃(SYNフラッド・UDPリフレクションなど)L3/L4に加え、WAFと組み合わせたアプリケーション層(L7)の攻撃
保護対象すべてのAWSリソースCloudFront、Route 53のホストゾーン、Global Accelerator、ELB、Elastic IP(EC2・NLB)
攻撃の可視化—攻撃の検出・詳細なメトリクスとレポート
専門チームの支援—Shield Response Team(SRT)による24時間の支援(Business Support+ 以上のサポートプランが必要)
費用の保護—攻撃で増えたスケーリング費用をクレジットで払い戻す
WAFの料金—保護対象リソースのWAF料金が含まれる

Shield Advanced の主な機能

  • 保護グループ:複数のリソースをまとめて1つの保護単位として扱う。
  • アプリケーション層の自動緩和:L7のDDoSを検出すると、WAFのルールを自動で作成・適用する。
  • ヘルスベースの検出:Route 53のヘルスチェックと関連付けて、検出の精度を上げる。
  • プロアクティブエンゲージメント:攻撃でヘルスチェックが異常になると、SRTから連絡が来る。
  • 攻撃の発生はCloudWatchメトリクス(DDoSDetected など)で監視できる。
  • Firewall Managerで組織全体のリソースに一括で適用できる。

DDoSに強い構成の基本

  • CloudFront・Route 53・Global Acceleratorなどのエッジのサービスを前に置き、攻撃をエッジで受ける。
  • ELBとAuto Scalingで、負荷が増えてもスケールできるようにする。
  • セキュリティグループで、オリジンには前段のサービスからの通信だけを許可する。

3. ユースケース

  • すべてのAWS利用者:Shield Standardで基本的なDDoS対策が自動で行われる
  • 止まると影響が大きいECサイトや金融サービス:Shield Advancedで攻撃の可視化とSRTの支援を受ける
  • 攻撃でスケールアウトした費用の払い戻しを受けたい場合

4. 料金の考え方

Shield Standardは無料です。Shield Advancedは組織単位の月額固定料金(1年契約)と、保護対象リソースのデータ転送量に応じた料金がかかります。1つの契約で、同じ組織(一括請求)の複数アカウントを保護できます。

5. 関連サービス

  • AWS WAF:アプリケーション層の攻撃対策
  • Amazon CloudFront/Amazon Route 53/AWS Global Accelerator:エッジで攻撃を受ける
  • Elastic Load Balancing/Amazon EC2 Auto Scaling:負荷の吸収
  • Amazon CloudWatch:攻撃の監視

6. 試験・実務でのポイント

  • 「DDoS」→ Shield。基本的なL3/L4の攻撃はStandard(無料・自動)で守られる。
  • 「24時間の専門チーム(SRT)」「攻撃による費用の補償」「高度なDDoS対策」→ Shield Advanced。
  • L7(HTTPフラッドなど)の対策は WAF のレートベースルールと組み合わせる。
  • Advancedの対象は CloudFront・Route 53・Global Accelerator・ELB・Elastic IP。

7. まとめ

  • ShieldはDDoS対策のサービス。Standardは全員に無料で適用される。
  • Advancedは攻撃の可視化・SRTの支援・費用の保護・L7の自動緩和を追加する。
