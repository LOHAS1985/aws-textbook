1. サービス概要

Kiroは、AWSが提供するAIエージェントを使った開発環境です。チャットでコードを書いてもらうだけでなく、要件 → 設計 → タスクの順に仕様(スペック)を作ってから実装を進める「仕様駆動開発」ができるのが特徴です。

デスクトップのIDE、ターミナルで使うCLI、ブラウザで使うWeb版などがあり、どれも同じエージェントの仕組みで動きます。プロジェクトの設定は、リポジトリの .kiro/ フォルダに保存され、チームで共有できます。Amazon Q Developer のIDE拡張・CLIの利用者向けに、Kiroへの移行ガイドが用意されています。

2. 主な機能・特徴

スペック(仕様駆動開発)

作りたい機能を伝えると、Kiroが次の3つの文書を作り、確認しながら実装を進めます。

文書内容
要件(requirements)ユーザーストーリーと受け入れ条件
設計(design)構成・データの流れ・インターフェイスなど
タスク(tasks)実装の手順を小さな作業に分けた一覧。1つずつ実行できる

不具合の修正用に、原因の分析と再発防止を含めて進めるバグ修正用のスペックもあります。

そのほかの主な機能

機能内容
ステアリングコーディング規約や使う技術など、プロジェクトの決まりをファイルに書いておくと、エージェントが常にそれに従う
フックファイルの保存やタスクの完了などをきっかけに、テストの作成やドキュメントの更新などを自動で実行する
MCP外部のツールやAPI(AWSのドキュメント、社内システムなど)をエージェントにつなぐ
権限とチェックポイントエージェントが使えるツールやコマンドを制限する。変更を前の状態に巻き戻せる
カスタムエージェント・スキル特定の作業向けのエージェントや、再利用できる手順をまとめて使う

サインインと組織での利用

個人はGoogle・GitHubのアカウントや AWS Builder ID でサインインします。企業での利用では、IAM Identity Center や外部のIdPでのシングルサインオン、利用状況の監視、請求のAWSへの一元化ができます。

3. ユースケース

  • 新しい機能を、要件と設計をレビューしてから実装する
  • CloudFormation・CDKなどのIaCのコードを、規約(ステアリング)に沿って作る
  • 保存のたびにテストを自動で更新し、品質を保つ
  • DevOps Agentが示したコードの改善案を実装する

4. 料金の考え方

利用者ごとの月額プラン(無料プランと、複数の有料プラン)で、プランごとに月のクレジットが付きます。クレジットはエージェントへの依頼の作業量に応じて消費され、複雑な作業ほど多く使います。有料プランでは追加のクレジットを購入できます。

5. 関連サービス

  • Amazon Bedrock:AWSの生成AIの基盤
  • AWS DevOps Agent:運用のためのAIエージェント
  • AWS Security Agent:セキュリティのためのAIエージェント
  • AWS IAM Identity Center:企業でのサインイン
  • AWS CDK/AWS CloudFormation:IaCのコードの生成先

6. 試験・実務でのポイント

  • 「要件・設計・タスクのスペックから実装を進めるAIの開発環境」→ Kiro。
  • プロジェクトの決まりを守らせる → ステアリング。イベントで自動実行 → フック。外部ツールとの接続 → MCP。
  • 企業での利用は IAM Identity Center などでのSSOで管理する。

7. まとめ

  • Kiroは、仕様駆動開発ができるAIエージェントの開発環境(IDE・CLIなど)。
  • ステアリング・フック・MCPで、チームの決まりや外部のツールを組み込める。
