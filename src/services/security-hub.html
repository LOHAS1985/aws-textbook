1. サービス概要

AWS Security Hubは、セキュリティの検出結果を集約し、コンプライアンス基準への準拠状況を一元管理するサービスです。

2025年に名称が整理され、このページで説明する「検出結果の集約とセキュリティ基準のチェック」を行う従来の機能はAWS Security Hub CSPMという名前になりました。「Security Hub」の名前は、GuardDuty・Inspector・Macie・Security Hub CSPMの結果を関連付けてリスクを分析する新しいサービス(2025年12月に一般提供開始)に使われています。試験や資料では、どちらを指しているかに注意します。

2. 主な機能・特徴

  • リージョン単位で有効化が必要。
  • Organizations全体を管理する場合は、委任管理者アカウントを使う。

集約する主なサービス

サービス検出する内容
GuardDuty不審なAPI操作、マルウェア
InspectorEC2・ECR・Lambdaの脆弱性
MacieS3内の機密データや公開リスク
Configリソース設定の非準拠

セキュリティチェック

  • 代表的なセキュリティ基準:AWS基礎セキュリティのベストプラクティス、CIS AWS Foundations Benchmark、PCI DSS
  • チェック内容の例:S3バケットが公開されていないか、CloudTrailが有効か、IAMユーザーにMFAが設定されているか
  • 検出結果のコンプライアンスステータス:PASSED(合格)、FAILED(不合格)、WARNING(判定できない。対象リソースタイプのConfigの記録が無効な場合など)、NOT_AVAILABLE(チェックを実行できなかった)
  • チェックはAWS Configのルールを使って行うため、AWS Configの記録を有効にしておく必要がある。なお、COMPLIANT/NON_COMPLIANT はConfigルール側の評価結果の値で、Security Hubの値とは異なる。

Security Hub Insights

検出結果をグループ化して可視化する機能です。

インシデント対応の自動化

例:公開されたセキュリティグループの修復

  1. Security Hubが検出
  2. EventBridgeルールで重要度や種類を判定
  3. Systems Manager AutomationまたはLambdaを起動
  4. 危険なインバウンドルールを削除
  5. Security Hubで再評価

関連サービスとの役割分担(Audit Managerとの統合)

サービス役割
Security Hubセキュリティ基準・コントロールに基づく継続的な評価
Audit Manager監査フレームワークに沿った証拠の収集・整理・レビュー
AWS Configリソース設定の記録とコンプライアンス評価
CloudTrailAPI操作の監査証跡

3. ユースケース

  • 複数のセキュリティサービスの検出結果を1つの画面で確認
  • CISやPCI DSSへの準拠状況の継続的なチェック
  • 組織全体のセキュリティ状況を管理アカウントに集約
  • 非準拠の設定の自動修復

4. 料金の考え方

セキュリティチェックの実行回数と、取り込んだ検出結果の数に応じて課金されます。

5. 関連サービス

  • Amazon Macie:S3の機密データ検出
  • AWS Config:設定の準拠評価
  • AWS CloudTrail:API操作の証跡
  • Amazon EventBridge:自動対応のトリガー
  • AWS Systems Manager:Automationによる修復
  • AWS Organizations:委任管理者
  • Amazon GuardDuty:脅威の検出
  • Amazon Inspector:脆弱性の検出
  • 関連する用語:コンプライアンスとAWS Artifact

6. 試験・実務でのポイント

  • 複数のセキュリティサービスの結果を集約 → Security Hub。
  • 有効化はリージョンごと。組織全体は委任管理者。
  • 自動修復 → EventBridge+SSM Automation/Lambda。
  • 監査の証拠集め → Audit Manager。
  • GuardDuty・Inspector・Macie・Security Hub CSPMの使い分け → セキュリティ検出のサービスの選び方。

7. まとめ

  • Security Hubはセキュリティ検出結果の集約と、基準への準拠チェックを行う。
  • EventBridgeと組み合わせてインシデント対応を自動化できる。
