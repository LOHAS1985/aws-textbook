1. サービス概要

Savings Plansは、1年または3年の期間、1時間あたり一定の金額を使うことを約束(コミット)する代わりに、オンデマンドより安い料金で使える割引の仕組みです。例えば「1時間あたり10ドル分を3年間使う」と約束すると、その金額までの利用に割引価格が適用されます。

リザーブドインスタンス(RI)が「インスタンスの種類」を約束するのに対し、Savings Plans は「金額」を約束するので、インスタンスの種類やリージョンを変えても割引が続く柔軟さがあります。

2. 主な機能・特徴

種類

種類割引(最大)対象柔軟さ
Compute Savings Plans66%EC2・Fargate・Lambdaインスタンスファミリー・サイズ・リージョン・OS・テナンシーを問わない
EC2 Instance Savings Plans72%EC2選んだリージョンの特定のインスタンスファミリー(例:東京のm5)。サイズ・OSは変えられる
Database Savings Plans35%Aurora・RDS・DynamoDB・ElastiCache・OpenSearch などエンジン・インスタンスファミリー・リージョンを問わない。サーバーレスにも適用
SageMaker AI Savings Plans64%SageMaker AIインスタンスファミリー・リージョン・用途を問わない

支払い方法と期間

  • 期間:1年または3年(3年の方が割引が大きい)
  • 支払い:全額前払い・一部前払い・前払いなし(前払いが多いほど割引が大きい)
  • 購入後に約束の内容は変更・解約できない。使用量が増えたら追加で購入する。

適用のされ方

  • 1時間ごとに、割引率の大きい利用から順に約束の金額まで自動で適用される。約束の金額を超えた分はオンデマンド料金。
  • 約束の金額に満たない時間があっても、約束の金額は支払う(使い残しは無駄になる)。
  • Organizationsの一括請求では、既定で他のアカウントの利用にも割引が共有される(共有はオフにできる)。
  • EKS・ECS・EMRのクラスターのEC2にも適用される(EKSのクラスター料金自体は対象外)。
  • 容量の予約はしない。特定のAZで容量を確保したい場合は、オンデマンドキャパシティ予約と組み合わせる。

購入量の決め方と効果の確認

Cost Explorer の推奨事項で、過去の使用量から最適な約束額を確認します。購入後は、使用率(約束した金額をどれだけ使えているか)とカバレッジ(利用のうち割引されている割合)のレポートで効果を確かめます。AWS Budgets で使用率・カバレッジの予算を設定し、下回ったら通知することもできます。

3. ユースケース

  • 常に動いているWebサーバーやバッチの基盤の費用を下げる
  • EC2からFargateやLambdaへ移行する予定があるので、どれにも使えるCompute Savings Plansを選ぶ
  • インスタンスファミリーを変える予定がない本番環境で、EC2 Instance Savings Plansで割引を最大にする

4. 料金の考え方

約束した1時間あたりの金額×期間の時間数を支払います(支払い方法に応じて前払いと月払いに分かれる)。使用量が約束を下回っても、約束の金額は請求されます。

5. 関連サービス

  • AWS Cost Explorer:推奨事項・使用率・カバレッジ
  • AWS Cost and Usage Reports:割引の適用の詳細
  • Amazon EC2/AWS Lambda/Amazon ECS(Fargate):割引の対象
  • AWS Organizations:割引の共有
  • AWS Compute Optimizer:購入前のサイズの適正化

6. 試験・実務でのポイント

  • 「EC2・Fargate・Lambdaにまたがって割引」「リージョンやファミリーを変えても割引」→ Compute Savings Plans。
  • 「特定のファミリー・リージョンで最大の割引」→ EC2 Instance Savings Plans。
  • Savings Plansは容量を予約しない。容量の確保はキャパシティ予約。
  • 中断してよい処理を最も安くするならスポットインスタンス。
  • 購入前にCompute Optimizerなどでサイズを適正化してから、約束額を決める。

7. まとめ

  • Savings Plansは、1時間あたりの利用額を1年・3年約束して割引を受ける仕組み。
  • 柔軟なCompute、割引の大きいEC2 Instanceを使い分け、Cost Explorerで推奨と効果を確認する。
