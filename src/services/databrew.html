1. サービス概要

AWS Glue DataBrewは、データを画面上で調査・プロファイルし、コードを書かずに整形・標準化するデータ準備ツールです。操作をレシピとして保存し、データセットに繰り返し適用できます。

2. 主な機能・特徴

プロファイルと変換レシピ

  • データの値の分布や欠損、型の不整合をプロファイルで確認する。
  • 画面で選んだ変換をレシピとして記録し、プレビューを見ながら順序を調整する。
  • 欠損値・異常値の処理、形式統一、列の分割・結合などの変換を行う。
  • 作成したレシピをジョブとして実行し、処理済みデータをS3などへ出力する。

Glueとの連携

DataBrewはビジュアルな探索・準備を行うAWS Glueの機能です。複雑な分岐や大規模な処理をコードで管理する場合はAWS Glue ETLジョブを使い、品質評価ルールを自動実行する場合はGlue Data Qualityを組み合わせます。

3. ユースケース

  • 分析担当者がCSVやデータレイクの値を調査して、欠損・不正値を見つける。
  • 異なる形式の日付やカテゴリ値を統一し、分析用データを作る。
  • レシピを定期ジョブとして実行し、同じ変換を再利用する。

4. 料金の考え方

プロジェクトやレシピジョブの実行など、利用する機能と処理量に応じて課金されます。S3の保存料金や、出力先の分析サービスの料金も考慮します。プロファイルの対象データ量やジョブの実行頻度を調整します。

5. 関連サービス

  • AWS Glue:Data Catalog、ETLジョブ、Data Quality
  • Amazon S3:入力・出力データの保存
  • Amazon Athena:準備済みデータのSQL分析
  • Amazon Redshift:準備済みデータの分析
  • 関連する用語:データ品質

6. 試験・実務でのポイント

  • コードを書かずにデータを可視化・整形し、レシピを再利用 → AWS Glue DataBrew。
  • プロファイルはデータの傾向を理解するもの、品質ルールは合否基準を継続的に検査するもの。
  • 変換のプレビューだけでなく、ジョブ出力のスキーマ・件数・品質を確認する。

7. まとめ

  • DataBrewは画面操作でデータを探索・整形するAWS Glueのツール。
  • 変換手順をレシピに保存し、ジョブで繰り返し実行できる。
