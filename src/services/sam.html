1. サービス概要

AWS SAM(Serverless Application Model)は、サーバーレスアプリケーションの開発・デプロイを支援するフレームワークです。CloudFormationのサーバーレス版で、CloudFormationだと長くなる記述を簡単に書けます。最終的にはCloudFormationに変換されます。

2. 主な機能・特徴

SAMテンプレート

対象リソース:Lambda関数/レイヤー、API Gateway、DynamoDBテーブル、Step Functions など

AWSTemplateFormatVersion: '2010-09-09'
Transform: AWS::Serverless-2016-10-31

Resources:
  HelloFunction:
    Type: AWS::Serverless::Function
    Properties:
      Runtime: nodejs22.x
      Handler: app.handler
      CodeUri: src/
      Events:
        Api:
          Type: Api
          Properties:
            Path: /hello
            Method: get

Transform: AWS::Serverless-2016-10-31 がSAMテンプレートの目印です。

SAM CLIのコマンド

コマンド内容
sam initプロジェクトのひな形を生成(ランタイム、アーキテクチャ、API有無、サンプルコードなど)
sam buildビルドして成果物を生成
sam local invokeLambdaを単体でローカル実行(Lambdaの単体テスト)
sam local start-apiAPI Gateway+Lambdaをローカル実行(http://127.0.0.1:3000)。リクエスト・レスポンスの検証
sam local start-lambdaLambdaエンドポイントをローカルに起動(http://127.0.0.1:3001)。他のLambdaやAWSサービスから正しく呼ばれるかを確認
sam local generate-eventテストイベントを生成
sam package成果物をS3などにアップロードし、クラウドから参照できる状態にする
sam deployデプロイ
sam sync --watch変更内容を高速にクラウドへ反映(既存リソースへの差分同期が目的)

設定ファイル samconfig.toml

複数環境で設定を変える場合などに使います。stack_name(スタック名)、region(リージョン)、capabilities(IAM作成の許可)、s3_bucket(パッケージの保存先)などを設定します。

段階的デプロイ

  1. SAMテンプレートに次の2つを記述:AutoPublishAlias: live、DeploymentPreference: Type: Canary10Percent5Minutes
  2. 初回デプロイ
  3. コードを修正して再デプロイ
  4. 段階的な移行が開始される(内部ではCodeDeployを使用)

SAMでデプロイするまでの流れ

  1. SAMテンプレートを作成し、Lambda・API・DynamoDBなどを定義
  2. sam build でビルド
  3. sam package/sam deploy でCloudFormationへ
  4. CloudFormationがAWSリソースを作成
コマンドインプット処理内容アウトプット
sam buildソースコード、template.yaml、依存関係の定義(requirements.txt、pom.xmlなど)依存関係を解決し、Lambda実行用の成果物を作成ビルド成果物
sam package.aws-sam/build/ の成果物、template.yaml成果物をZIP化してS3へアップロードし、CodeUri をS3パスに置き換えパッケージ済みテンプレート(packaged.yaml など)
sam deployパッケージ済みテンプレートCloudFormationスタックを作成・更新Lambda関数・API GatewayなどのAWSリソース

3. ユースケース

  • API Gateway+Lambda+DynamoDBのサーバーレスAPIを少ない記述で構築
  • ローカルでLambdaやAPIをテストしてからデプロイ
  • Lambdaの新バージョンをCanaryで段階的にリリース

4. 料金の考え方

SAM自体は無料のオープンソースフレームワークです。作成されたLambdaなどのリソースや、パッケージを置くS3に料金がかかります。

5. 関連サービス

  • AWS CloudFormation:SAMの変換先
  • AWS Lambda/Amazon API Gateway/Amazon DynamoDB/AWS Step Functions:SAMで定義する主なリソース
  • AWS CodeDeploy:段階的デプロイの実行
  • AWS CDK:プログラミング言語によるIaC

6. 試験・実務でのポイント

  • SAMテンプレートの目印 → Transform: AWS::Serverless-2016-10-31。
  • Lambda単体のローカルテスト → sam local invoke。APIとしてローカル実行 → sam local start-api。
  • 開発中に変更をすばやく反映 → sam sync --watch。
  • Canaryで段階的デプロイ → AutoPublishAlias+DeploymentPreference。
  • 環境ごとの設定 → samconfig.toml。

7. まとめ

  • SAMはサーバーレス向けにCloudFormationを簡単に書けるフレームワーク。
  • SAM CLIでビルド・ローカル実行・デプロイ・同期ができる。
