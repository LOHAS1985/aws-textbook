1. サービス概要

AWS Control Towerは、ベストプラクティスに沿ったマルチアカウント環境(ランディングゾーン)を短時間で作り、継続的に統制するサービスです。

Organizations・IAM Identity Center・Service Catalog・Config・CloudTrail などを組み合わせた構成を、Control Tower が代わりに組み立てて管理します。Organizationsを直接使うよりも、「最初からあるべき形」が用意されている点が特徴です。

2. 主な機能・特徴

ランディングゾーン

セキュリティとコンプライアンスのベストプラクティスに沿った、マルチアカウントの環境です。作成すると、次のようなものが用意されます。

  • 管理アカウントのもとに Security OU を作り、その中にログアーカイブアカウント(全アカウントのCloudTrail・Configのログを集約)と監査アカウント(セキュリティチームが全アカウントを確認する)を置く
  • 組織全体のCloudTrailの証跡とConfigの記録
  • IAM Identity Center によるシングルサインオン
  • 必須のコントロール

コントロール(ガードレール)

環境全体を統制するルールです。動作の種類は3つあります。

種類動き実装
予防型違反する操作をそもそもできなくするSCP・RCP
検出型違反しているリソースを見つけて知らせるConfigルール
事前対応型(プロアクティブ)違反するリソースを作る前に止めるCloudFormationフック

適用の度合いとして、必須(常に有効・無効にできない)・強く推奨・選択の3段階があります。コントロールはOU単位で有効化します。

Account Factory

あらかじめ決めた設定(OU・ネットワークなど)で、新しいアカウントを作る仕組みです。作られたアカウントには、所属するOUのコントロールが自動で適用されます。Terraformで定義する Account Factory for Terraform(AFT)や、アカウントのカスタマイズ用のブループリントもあります。

ドリフト

Control Tower の外(Organizationsの画面など)で、OUの移動やSCPの変更を行うと、ランディングゾーンの状態と食い違う「ドリフト」になります。ダッシュボードで確認し、ランディングゾーンの修復(リセット)で元に戻します。

既存の環境への導入

既存のOrganizationsの組織に対しても有効化できます。既存のOUを登録し、既存のアカウントを登録(enroll)すると、Control Tower の管理下に入ります。

3. ユースケース

  • これからマルチアカウントの環境を作る組織が、ベストプラクティスの構成をすぐに用意する
  • 「本番OUではリージョンを東京と大阪に限る」「ログの削除を禁止する」といったルールを組織全体に強制する
  • 開発チームの依頼に応じて、統制の効いたアカウントをすぐに払い出す

4. 料金の考え方

Control Tower 自体は無料です。裏で使われる Config・CloudTrail・S3・Service Catalogなどのサービスの料金がかかります。アカウント数・リージョン数・検出型コントロールが増えると、Configの記録や評価の費用も増えます。リソースの作成と削除をくり返す環境(スポットインスタンスやAuto Scalingが多いなど)では、Configの費用が大きくなりやすい点に注意します。

5. 関連サービス

  • AWS Organizations:OUとSCP(土台)
  • AWS IAM Identity Center:シングルサインオン
  • AWS Config:検出型コントロール
  • AWS CloudTrail:組織の証跡
  • AWS Service Catalog:Account Factory の仕組み
  • AWS CloudFormation:事前対応型コントロール(フック)
  • 組織のガードレール(運用シナリオ)

6. 試験・実務でのポイント

  • 「ベストプラクティスに沿ったマルチアカウント環境をすばやく作る」「ランディングゾーン」→ Control Tower。
  • 予防型=SCP、検出型=Configルール、事前対応型=CloudFormationフック。
  • 統制の効いた新しいアカウントの作成 → Account Factory。
  • Control Tower の外で変更してドリフトした → ランディングゾーンを修復する。
  • 細かく自分で組み立てたいならOrganizationsを直接使う。

7. まとめ

  • Control Tower は、Organizationsなどを組み合わせたマルチアカウント環境を作り、コントロールで統制する。
  • ログアーカイブ・監査アカウント、組織の証跡、SSOが最初から用意される。
