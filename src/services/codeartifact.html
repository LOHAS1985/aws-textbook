1. サービス概要

AWS CodeArtifactは、ソフトウェアパッケージを保存・共有するためのリポジトリサービスです。開発で使うライブラリを組織内で共有・管理します。

2. 主な機能・特徴

対応するパッケージの例

  • Java:Mavenライブラリ
  • Node.js:npmパッケージ
  • Python:pipパッケージ
  • npmjs.comやPyPIなどの公開リポジトリを上流(アップストリーム)として接続し、取得したパッケージをキャッシュできる。
  • リポジトリはドメイン単位でまとめて管理し、IAMでアクセスを制御する。
  • 社内で作った独自パッケージを公開・共有できる。

3. ユースケース

  • 社内共通ライブラリをチームで共有
  • インターネットに出られないビルド環境で、承認済みのパッケージだけを使わせる
  • CodeBuildの依存パッケージ取得元として利用

4. 料金の考え方

保存しているパッケージの容量、リクエスト数、データ転送量に応じて課金されます。

5. 関連サービス

  • AWS CodeBuild:ビルド時の依存取得
  • Amazon ECR:コンテナイメージのリポジトリ
  • AWS IAM:アクセス制御

6. 試験・実務でのポイント

  • npm・pip・Mavenのパッケージを組織内で管理 → CodeArtifact。
  • コンテナイメージの管理 → ECR(混同に注意)。

7. まとめ

  • CodeArtifactはMaven・npm・pipなどのパッケージを保存・共有するリポジトリ。
