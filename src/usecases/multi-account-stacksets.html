1. やりたいこと

組織内のすべてのアカウント・リージョンに、監視用のIAMロールやConfigルールなどの共通設定を同じ内容で作りたい。新しくアカウントを追加したときにも、自動で同じ設定が入るようにしたい。

2. 構成図

3. 使うサービスと役割

  • AWS CloudFormation:StackSetsで複数アカウント・リージョンへ一括展開する
  • AWS Organizations:展開先をOUで指定する
  • AWS Config/AWS IAM:展開する設定の例(Configルール、運用用のロール)

4. 構築の流れ

  1. 共通設定をCloudFormationテンプレートにする
  2. OrganizationsでStackSetsの信頼されたアクセスを有効にし、サービスマネージドのアクセス許可を使う
  3. 管理アカウントでStackSetを作成し、展開先のOUとリージョンを指定する
  4. 自動デプロイを有効にして、新しいアカウントにも自動で展開されるようにする
  5. 同時に展開するアカウント数と、失敗の許容数を設定して少しずつ展開する

5. ポイント・注意点

  • 複数アカウント・リージョンに同じスタック → StackSets。
  • テンプレートにIAMリソースを含む場合は、CAPABILITY_IAM などの許可が必要。
  • 秘密情報はテンプレートに書かず、ダイナミックリファレンスで参照する。
  • 決まった構成を利用者自身に起動させたいならService Catalogも候補。
