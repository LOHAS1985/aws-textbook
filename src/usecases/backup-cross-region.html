1. やりたいこと

EC2・EBS・RDS・EFSなどのバックアップを、サービスごとにばらばらに設定するのではなく一元管理したい。新しく作ったリソースも自動で対象にし、リージョン障害に備えて別リージョンにもコピーを残したい。

2. 構成図

3. 使うサービスと役割

  • AWS Backup:バックアッププラン(スケジュール・保持期間・コピー先)、リソースの割り当て(タグ/ARN)、ボールト
  • AWS Organizations:組織全体にバックアップポリシーを適用する
  • AWS KMS:バックアップの暗号化

4. 構築の流れ

  1. バックアップボールトを作成する(コピー先のリージョンにも作成)
  2. バックアッププランを作成し、スケジュール・バックアップウィンドウ・保持期間・ライフサイクルを設定する
  3. プランのコピー先に、別リージョンのボールトを指定する
  4. リソースの割り当てで、対象をタグ(例:Backup=daily)で指定する
  5. 定期的に復元をテストして、実際に戻せることを確認する

5. ポイント・注意点

  • 複数サービスのバックアップを一元管理 → AWS Backup。
  • 対象をタグで指定すると、新しく作ったリソースも自動で対象になる。
  • リージョン障害への備え → 別リージョンへのコピー(DR戦略の「バックアップと復元」)。
  • バックアップを誰にも削除させたくない → ボールトロック。
