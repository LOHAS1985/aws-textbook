1. やりたいこと

  • 数百台のEC2に、CloudWatchエージェントを入れて同じ設定にしておきたい。
  • 新しく起動したインスタンスにも自動で入り、設定が変えられても元に戻したい。
  • SSHでログインして1台ずつ作業するのはやめたい。

2. 構成を組み立てる

① 決めた状態を、新しいインスタンスにも定期的に適用し続けるものは?

  • Systems Manager State Manager関連付けで、対象とスケジュールを決めて状態を適用し続けます。設定が変えられても次の適用で戻ります。
  • EC2のユーザーデータ起動時に1回実行されるだけで、その後の変更は元に戻せません。
  • Systems Manager Inventory導入済みのソフトなどの一覧を集めるだけで、設定は適用しません。

② その場で1回だけ、全台にコマンドを実行するものは?

  • Systems Manager Run CommandSSHなしで、タグで選んだインスタンスにコマンドを一括実行します。同時実行数とエラーのしきい値も決められます。
  • Session Manager1台ずつ対話的に操作するもので、一括実行には向きません。
  • AWS CloudShellブラウザでAWS CLIを使う環境で、インスタンスの中でコマンドは実行しません。

③ Systems Managerの一覧にインスタンスが出ない原因は?

  • SSMエージェント・IAMロール・SSMへの経路のどれかが欠けているインスタンスプロファイルに AmazonSSMManagedInstanceCore を付け、NATかVPCエンドポイントでSSMに届くようにします(VPCエンドポイント)。
  • キーペアが設定されていないSystems ManagerはSSHを使わないので、キーペアは不要です。
  • セキュリティグループで22番を開けていないエージェントは外向きのHTTPSでつなぐため、受信のポートは不要です。

3. 構成図

状態の維持はState Manager、その場の作業はRun Commandで行います。対象はインスタンスIDではなくタグで指定すると、台数が増えても設定を変えずに済みます。操作の記録はCloudTrail、コマンドの出力はS3やCloudWatch Logsに残ります。

4. 使うサービスと役割

  • AWS Systems Manager:State Manager(状態の維持)、Run Command(一括実行)、Distributor(ソフトのパッケージ配布)、Inventory(導入済みソフトの一覧)、Parameter Store(エージェントの設定)
  • Amazon EC2:SSMエージェントとIAMロール(マネージドノードにする)
  • Amazon CloudWatch:エージェントの設定の配布先、コマンドの出力の保存先
  • Amazon S3:コマンドの出力の保存先

5. 構築の流れ

  1. インスタンスをマネージドノードにする:SSMエージェント(主要なAMIには導入済み)と、AmazonSSMManagedInstanceCore を含むIAMロール。アカウント全体で自動化するならデフォルトのホスト管理設定(DHMC)を使う
  2. プライベートサブネットなら、SSM用のVPCエンドポイント(ssm・ssmmessages・ec2messages)かNATゲートウェイを用意する
  3. State Managerの関連付けを作る:ドキュメント(例:AWS-ConfigureAWSPackage でCloudWatchエージェントを導入)、対象(タグ)、スケジュールを指定する
  4. レート制御(同時実行数・エラーのしきい値)を設定し、一度に全台が影響を受けないようにする
  5. 実行結果をS3・CloudWatch Logsに保存し、Inventoryで導入状況を確認する。準拠状況はSystems Managerの「コンプライアンス」で見る

6. ポイント・注意点

  • 決めた状態を維持し続ける(新しいインスタンスにも自動で適用)→ State Manager。その場で1回実行 → Run Command。
  • Systems Managerの一覧にインスタンスが出ない → SSMエージェント・IAMロール・SSMのエンドポイントへの経路のどれかが原因。
  • 対象はインスタンスIDではなくタグで指定すると、台数が増えても設定を変えずに済む。
  • レート制御で同時実行数とエラーのしきい値を決め、失敗が広がったら止める。
  • SSHやキーペアは不要。操作の記録はCloudTrail、コマンドの出力はS3・CloudWatch Logsに残る。
