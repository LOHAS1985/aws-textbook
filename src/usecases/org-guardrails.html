1. やりたいこと

組織内のすべてのアカウントで、「東京・大阪以外のリージョンを使わせない」「CloudTrailを止めさせない」といったルールを強制したい。あわせて、全アカウントの操作履歴と設定の準拠状況を管理アカウントでまとめて確認したい。

3. 使うサービスと役割

  • AWS Organizations:OUとSCP(サービスコントロールポリシー)
  • AWS CloudTrail:組織の証跡で全アカウントのAPI操作を記録する
  • AWS Config:組織全体のルール、Conformance Packs
  • AWS Security Hub:委任管理者アカウントで組織全体の検出結果を集約する
  • AWS IAM:SCPの範囲内で個々の権限を与える

4. 構築の流れ

  1. Organizationsでアカウントを OU(本番・開発など)に整理する
  2. SCPを作成し(例:許可リージョン以外の操作を拒否、CloudTrailの停止を拒否)、ルートまたはOUに適用する
  3. CloudTrailの組織の証跡を作成し、ログ集約用のS3に保存する
  4. Configのルール(またはConformance Packs)を組織全体に展開し、Security Hubの委任管理者を設定する

5. ポイント・注意点

  • SCPは権限を与えない。上限(ガードレール)を決めるだけで、実際に操作するにはIAMでの許可も必要。
  • IAMで許可しても、SCPで拒否されていれば実行できない。
  • SCPは管理アカウントには適用されない。
  • 組織の証跡は、メンバーアカウント側から停止・削除できない。
