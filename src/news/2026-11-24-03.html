1. 発表の内容

Global Accelerator(世界中の利用者を、AWS のネットワーク経由で最寄りのエンドポイントへ導くサービス)は、「クライアント IP アドレスの保持」を有効にすると、アプリ側で利用者の本当の IP アドレスを見られます。これまでは、この設定をした高速化の対象に、TLS リスナーを持つ NLB(Network Load Balancer。TLS の暗号化をここで解く)を追加できませんでした。TLS を NLB で終わらせるか、クライアント IP を見るかの二択でした。今回、両方を同時に使えます。

追加の設定は不要で、通常の NLB と同じようにエンドポイントへ追加するだけです。HTTP 以外の TCP 通信、固定 IP が必要なアプリ、大量の通信など、レイヤー7のロードバランサーが向かない場面で役立ちます。

何がうれしいか
本当のクライアント IP をもとにした、セキュリティグループでの制限、地域によるブロック、レート制限、不正検知、監査ログ、許可リストが使えます。追加料金はなく、通常の Global Accelerator の料金です。
試験・実務への影響
クライアント IP を見る必要があるときに、プロキシ経由で IP が変わる点は定番の論点です。Global Accelerator と NLB の組み合わせで解決できることを覚えておきましょう。GovCloud と中国のリージョンは対象外です。
