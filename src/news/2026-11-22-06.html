1. 発表の内容

Lambda の Event Function の状態が変わるたびに、イベントが EventBridge へ自動で送られます。関数が呼び出せる状態になったか、更新が終わったか、失敗したかを、GetFunction API のポーリングなしで検知でき、Step Functions・SNS・SQS などへ渡せます。追加料金はなく、ルールの対象に標準の料金がかかります。
