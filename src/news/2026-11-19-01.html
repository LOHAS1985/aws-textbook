1. 発表の内容

複数の VPC をつなぐハブである Transit Gateway は、通信をファイアウォールなどのセキュリティ機器へ通してから届けたい場面でよく使われます。機器は Gateway Load Balancer(GWLB。機器をまとめて負荷分散するロードバランサー)の背後に置きますが、これまでは検査用の VPC に GWLB エンドポイント専用のサブネットとルートテーブルを自分で作る必要がありました。

今回、Transit Gateway に Gateway Load Balancer 型のネットワークファンクションアタッチメントが追加されました。GWLB のエンドポイントサービスを指定すると、選んだアベイラビリティーゾーンにエンドポイントを Transit Gateway が作って管理します。エンドポイントサービスは別アカウントにあっても構いません。また、通信を送るときに、どのアタッチメント・VPC・サブネット・セキュリティグループから来たかという情報を付け、ファイアウォール側が IP アドレスだけでなくこの情報でもセグメント分離のルールを決められます。

何がうれしいか
検査用 VPC の複雑なサブネット・ルート設計が減り、ファイアウォールの集中配置を簡単に作れます。
試験・実務への影響
ネットワーク・コンテンツ配信やセキュリティの分野で、複数 VPC の通信を集中検査する構成は定番です。Transit Gateway と GWLB の組み合わせとして押さえておきましょう。
