1. 発表の内容

Envoy は、通信の振り分けや認証、ルーティングの細かな制御ができるオープンソースのプロキシ(クライアントとサーバーの間で通信を中継するソフトウェア)です。自分で Envoy を動かすと、バージョンアップ、脆弱性への対応、アベイラビリティーゾーン(AZ)をまたいだ容量の確保をすべて自分で行う必要がありました。

今回一般提供になった ELB for Envoy は、Elastic Load Balancing に加わった新しい種類のロードバランサーです。Envoy のプロキシを、ロードバランサーごとに専用の EC2 インスタンス(Nitro System によるハードウェア分離つき)で動かします。脆弱性(CVE)の監視と、Envoy や OS のパッチ適用は AWS が自動で行います。

手元の Envoy の設定や拡張機能、コントロールプレーンをそのまま持ち込めて、ACM(証明書)や AWS WAF とも少ない設定でつなげられます。WebAssembly や Lua スクリプトで独自の処理を足すこともできます。VPC の中で動き、セキュリティグループにも対応します。Kubernetes の Envoy Gateway を使っている場合は、Gateway API のリソースを書き直さずに移行できます。東京を含む14リージョンで使えます。

何がうれしいか
Envoy ならではの細かな制御を使いながら、パッチ適用や容量確保といった運用の負担を減らせます。
試験・実務への影響
通常の用途では ALB・NLB を選び、Envoy の拡張性が必要な場合に ELB for Envoy、という使い分けを押さえましょう。
