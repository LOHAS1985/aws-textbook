1. 発表の内容

CloudWatch Omni(複数のクラウドや環境の監視データを1か所で見るための機能)が、Microsoft Azure のデータの収集に対応しました。集められるのは、Azure のリソースログ、Azure Monitor のプラットフォームメトリクス、仮想ネットワーク(VNet)のフローログ、Application Insights のトレースです。

設定は、Microsoft Entra ID(Azure のユーザー管理サービス)のテナントを AWS アカウントとリージョンに接続するところから始めます。集めるデータの種類・サブスクリプション・Azure のリージョン・リソースの種類・タグを選べます。集めたデータは CloudWatch に入り、障害の調査では Azure 上のサービスの遅いリクエストから AWS 側の依存先まで、画面を切り替えずにたどれます。

何がうれしいか
AWS と Azure の両方で動かしているシステムでも、監視ツールを分けたり自前の収集の仕組みを作ったりせずに、全体を1つの画面で見られます。
試験・実務への影響
CloudWatch は AWS の中だけでなく、他のクラウドのデータも集める方向に広がっています。取り込んだデータには CloudWatch の料金がかかる点も覚えておきましょう。
