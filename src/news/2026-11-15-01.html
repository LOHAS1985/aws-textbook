1. 発表の内容

AWS Systems Manager は、サーバーの管理(コマンド実行、パッチ適用、構成の維持など)を一か所から行うサービスです。管理したいサーバーには SSM Agent(管理用の常駐プログラム)を入れる必要があります。Cloud Connector は、AWS 以外のクラウドにあるサーバーを Systems Manager につなぐ機能で、これまで Azure に対応していました。今回、Google Cloud の仮想マシン(VM)にも対応しました。

Google Cloud 側の VM へ、SSM Agent を手作業で入れて回る必要がありません。多数の VM へ自動で配布できます。つないだ VM は、EC2 インスタンスやオンプレミスのサーバーと同じ一覧に並び、Session Manager(ブラウザーからの接続)、Run Command、Patch Manager などを同じ手順で使えます。

何がうれしいか
複数のクラウドを使っていても、パッチ適用や作業の自動化を同じ方法でそろえられ、運用の手間が減ります。
試験・実務への影響
Systems Manager は、AWS だけでなくオンプレミスや他クラウドのサーバーも管理できる、というのが運用の定番の出題ポイントです。対象が Google Cloud まで広がったと押さえておきましょう。
