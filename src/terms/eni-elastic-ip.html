1. 詳しい説明

ENI(Elastic Network Interface)

ENIは、VPCの中で使う仮想的なネットワークカード(NIC)です。EC2がVPC内で通信できるのは、ENIがアタッチされているからです。IPアドレスやセキュリティグループは、実はインスタンスではなくENIに付いています。

  • ENIが持つもの:プライベートIPアドレス(1つの主アドレス+追加のセカンダリアドレス)、パブリックIPアドレス(割り当てた場合)、セキュリティグループ、MACアドレス
  • ENIは特定のサブネット(=特定のAZ)に作成される。
  • インスタンスに最初から付いているプライマリENIは取り外せない。追加で作ったENIは取り外して、同じAZの別のインスタンスに付け替えられる(IPアドレスやセキュリティグループもそのまま移る)。
  • EC2以外でも、Lambda(VPC接続)、RDS、ELB、VPCエンドポイント(インターフェイス型)、EFSのマウントターゲットなどが、サブネット内にENIを作って通信している。

パブリックIPアドレスとElastic IP

インターネットと通信するEC2には、プライベートIPのほかにパブリックIPアドレスが必要です(さらに、サブネットのルートテーブルにインターネットゲートウェイへの経路も必要)。パブリックIPには2種類あります。

項目自動割り当てのパブリックIPElastic IP
取得方法サブネットの設定や起動時の設定で自動的に割り当てるアカウントに確保し、インスタンス(ENI)に関連付ける
停止・起動したとき変わる(停止すると解放され、起動時に別のIPが付く)変わらない
付け替えできない別のインスタンスへ付け替えられる(障害時の切り替えに使える)
上限-既定ではリージョンごとに5個(引き上げを申請できる)

2024年2月から、パブリックIPv4アドレスはすべて時間単位で課金されます(使用中のElastic IP、自動割り当てのパブリックIPも含む)。確保したまま使っていないElastic IPも課金されるため、不要になったら解放します。

「停止・起動したらIPアドレスが変わって接続できなくなった」→ 固定したいならElastic IP。ただし、Webサービスの入り口を固定したい場合は、ELBやRoute 53のDNS名、Global Acceleratorの固定IPを使う方法もあります。

2. 関連する用語

  • CIDR:ENIのプライベートIPはサブネットのCIDRから割り当てられる
  • ネットワークACLとセキュリティグループ:セキュリティグループはENI単位で適用される
  • VPCエンドポイント:インターフェイス型はサブネット内のENIとして作られる
  • アウトバウンド通信:パブリックIPとNATゲートウェイの使い分け

3. 関連サービス

  • Amazon EC2:ENIとパブリックIP・Elastic IPを使う代表的なリソース
  • Amazon VPC:ENIを作るサブネット
  • AWS Lambda:VPC接続でENIを使う
  • Elastic Load Balancing:NLBにはElastic IPを割り当てられる
  • AWS Global Accelerator:固定のAnycast IPで入り口を固定
