料金の基本

使った分だけ払う従量課金の考え方と、見落としやすいデータ転送料金・無料利用枠・割引の仕組み

最終更新:2026-10-26

1. 詳しい説明#

AWSの料金は、基本的に使った分だけ払う従量課金です。初期費用や長期の契約はなく、止めたり削除したりすれば料金もかからなくなります。料金は主に次の要素の組み合わせで決まります。

要素単位例
コンピューティング動かした時間(秒・時間)、リクエスト数EC2(Linuxは秒単位、最低60秒)、Lambda(リクエスト数と実行時間)
ストレージ保存した量 × 期間(GB・月)S3、EBS(アタッチしていなくても確保した容量に課金)、スナップショット
リクエスト・処理量回数・処理したデータ量S3のPUT・GET、NATゲートウェイの処理量、CloudWatch Logsの取り込み量
データ転送送ったデータ量(GB)インターネットへの送信、AZ間・リージョン間の通信
時間単位の固定費存在する時間NATゲートウェイ、ロードバランサー、パブリックIPv4アドレス、インターフェイス型VPCエンドポイント

データ転送料金#

見落としやすく、想定外の請求の原因になりやすいのがデータ転送料金です。入ってくる通信は無料、出ていく通信は有料が基本です。

  • インターネットへの送信は、毎月一定量(全サービス合計で100GB)まで無料
  • 同じリージョンのS3・DynamoDBとの通信は、ゲートウェイ型のVPCエンドポイントを使えば無料で、NATゲートウェイの処理料金もかからない
  • CloudFrontからの配信は、EC2やS3から直接インターネットに送るより安くなることが多い。オリジン(AWS内)からCloudFrontへの転送は無料
  • NATゲートウェイは、時間料金に加えて処理したデータ量でも課金される。他のAZのNATゲートウェイを通すと、AZ間の転送料金も加わる

割引の仕組み#

方法内容向いている使い方
オンデマンド割引なし。いつでも開始・停止できる短期間・予測できない使い方
Savings Plans1年か3年、1時間あたりの利用額を約束して割引ずっと動かし続ける部分(EC2・Fargate・Lambda)
リザーブドインスタンス1年か3年、インスタンスの種類などを約束して割引RDS・ElastiCache・OpenSearchなど、Savings Plansの対象外のサービス
スポットインスタンス余っている容量を大幅な割引で使う。2分前の通知で中断されることがある中断されてもよい処理(バッチ・CI・ステートレスな処理)

無料利用枠#

新しく作ったアカウントにはクレジット(最初に100ドル、主要なサービスを試すとさらに最大100ドル)が付きます。アカウントの作成時に次の2つのプランを選びます。

  • 無料プラン:クレジットと無料の範囲だけで使え、料金は請求されない。作成から6か月か、クレジットを使い切ると終了する(続けるには有料プランに切り替える)。使えるサービスに制限がある
  • 有料プラン:すべてのサービスを従量課金で使える。クレジットは料金に自動で充当される

どちらのプランでも、30以上のサービスには毎月一定量までずっと無料の枠があります(Lambdaのリクエスト、DynamoDBの容量など)。

費用を見て、管理する#

  • AWS Pricing Calculator:作る前に費用を見積もる
  • AWS Budgets:予算を決めて、超えそう・超えたときに通知する(予算アクションで権限の制限やインスタンスの停止も可能)
  • Cost Explorer:費用の内訳と推移を見る。コスト配分タグでプロジェクトごとに集計する
  • コスト異常検出:いつもと違う費用の増え方を見つけて通知する

「使っていないのに請求が続く」原因の典型は、停止したEC2のEBSボリューム、アタッチしていないEBS・Elastic IP、古いスナップショット、使っていないNATゲートウェイやロードバランサーです。EC2は停止すればインスタンスの料金は止まりますが、EBSの料金はかかり続けます。

2. 関連する用語#

  • コスト管理ツールの選び方:Budgets・Cost Explorer・CURなどの使い分け
  • タグ:コスト配分タグ
  • VPCエンドポイント:NATゲートウェイの料金を減らす
  • リージョンとアベイラビリティーゾーン:AZ間・リージョン間の通信
  • サポートプラン:サポートの料金

3. 関連サービス#

  • AWS Cost Explorer:費用の分析
  • AWS Cost and Usage Reports:詳細な請求データ
  • Savings Plans:利用額の約束による割引
  • Amazon EC2:購入オプション(オンデマンド・RI・スポット)
  • Amazon CloudFront:配信の転送料金を下げる
  • AWS Compute Optimizer:サイズの見直し

この用語が出てくるページ#

  • AWS Cost ExplorerサービスAWSの料金と使用量をグラフで分析し、将来の費用を予測する
  • AWS Cost and Usage Reportsサービス最も詳細な料金・使用量のデータを、S3にファイルとして定期的に出力する
  • Savings Plansサービス1年または3年の利用額(1時間あたりの金額)を約束して、コンピューティングなどの料金を割り引く
