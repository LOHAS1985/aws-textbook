2. 分野・配点・タスク#

分野配点タスク
SDLC自動化
SDLC Automation		22%1.1 CI/CDパイプラインの実装
1.2 CI/CDパイプラインへの自動テストの統合
1.3 アーティファクトのビルドと管理
1.4 インスタンス、コンテナ、サーバーレス環境向けのデプロイ戦略の実装
構成管理とIaC
Configuration Management and IaC		17%2.1 システムのライフサイクル全体でプロビジョニングと管理を行うための、クラウドインフラと再利用可能なコンポーネントの定義
2.2 マルチアカウントまたはマルチリージョン環境でAWSアカウントを作成、オンボーディング、セキュア化する自動化のデプロイ
2.3 複雑なタスクと大規模環境向けの自動化ソリューションの設計と構築
回復力のあるクラウドソリューション
Resilient Cloud Solutions		15%3.1 回復力とビジネス要件を満たす高可用性ソリューションの実装
3.2 ビジネス要件を満たすスケーラブルなソリューションの実装
3.3 RTOとRPOの要件を満たす自動化された復旧プロセスの実装
監視とロギング
Monitoring and Logging		15%4.1 ログとメトリクスの収集、集約、保存の設定
4.2 問題を検出するためのログとメトリクスの監査、監視、分析
4.3 複雑な環境の監視とイベント管理の自動化
インシデントとイベントへの対応
Incident and Event Response		14%5.1 イベントソースの管理と、イベントに応じた処理、通知、アクションの実行
5.2 イベントに応じた構成変更の実装
5.3 システムとアプリケーション障害のトラブルシューティング
セキュリティとコンプライアンス
Security and Compliance		17%6.1 大規模な ID とアクセス管理の手法の実装
6.2 セキュリティ統制とデータ保護への自動化の適用
6.3 セキュリティ監視と監査ソリューションの実装
