選び方診断

いくつかの質問に答えると、目的に合うサービスの候補を絞り込みます

JavaScript が動くと、質問に答えて候補を絞り込めます。候補は代表的な例です。要件に合うかは、各サービスのページで確認してください。

質問

  1. 何をしたいですか:プログラムを動かす(サーバー・関数・コンテナ)・データを保存する・配信する・データを保存して検索・更新する・ネットワークを作る・接続する・サービス同士をつないで処理を連携する
  2. サーバーの管理をどこまで任せたいですか:管理したくない(AWSに任せたい)・コンテナで動かしたい・OSごと自分で管理したい・指定しない
  3. データの形は:表形式(SQLで検索する)・キーと値(一定の形で速く取り出す)・JSONなどのドキュメント・関係(グラフ)をたどる・大量データを集計・分析する・指定しない・ファイル単位(画像・ログなど)・共有フォルダのようなファイル・OSのディスク(ブロック)
  4. 応答の速さは:ミリ秒単位で応答する必要がある・数十ミリ秒〜秒単位で足りる、または指定しない
  5. アクセスの経路は:インターネットから直接アクセスさせる・オンプレミスの社内ネットワークとつなぐ・指定しない
