コスト管理ツールの選び方

Cost Explorer・Budgets・CUR・Compute Optimizer・Trusted Advisor・Savings Plansを目的で使い分ける

最終更新:2026-10-26

1. 詳しい説明#

AWSの費用を管理するツールは、目的ごとに分かれています。見える化する(何にいくらかかっているか)、異常に気づく(予算超過や急な増加)、無駄を減らす(使いすぎのサイズや放置されたリソース)、割引で安くする(長期利用の約束)の4つです。この4つを繰り返し回していくのが、コスト最適化の基本の進め方です。

比較表#

ツール目的できることデータの細かさ
Cost Explorer見える化サービス・アカウント・タグ別の費用をグラフで見る。今後の費用の予測、Savings Plans・RIの購入の推奨日単位・月単位(時間単位も有効にできる)
Cost and Usage Reports(CUR 2.0)見える化最も詳しい請求データをS3に出力し、AthenaやQuickSightで分析する時間単位・リソース単位
AWS Budgets異常に気づく予算を決め、実績や予測がしきい値を超えたら通知する。超えたときにIAMポリシーの適用やEC2の停止などのアクションも実行できる月・四半期・年の予算
Cost Anomaly Detection異常に気づく機械学習で普段と違う費用の増え方を見つけて通知する日単位
Compute Optimizer無駄を減らすEC2・Auto Scalingグループ・EBS・Lambdaなどの使用状況から、適切なサイズを推奨するリソース単位
Trusted Advisor無駄を減らす使われていないEBS・Elastic IP、使用率の低いEC2などをチェックするリソース単位
Savings Plans・リザーブドインスタンス(RI)割引で安くする1年または3年の利用を約束して、オンデマンドより安くする—

コスト配分タグ#

部署やプロジェクトごとの費用を知るには、リソースにタグ(例: Project=web)を付けます。ただし、タグを付けただけでは費用の集計に使えません。Billingのコンソールでそのタグをコスト配分タグとして有効化すると、Cost ExplorerやCURでタグごとに集計できるようになります(有効化より前の費用には反映されません)。

選び方のポイント#

  • 予算を超えそうなときに通知を受けたい(予測値でも可) → AWS Budgets。
  • 予算を超えたら自動でEC2を止めたり、新しいリソースを作れなくしたりしたい → Budgetsのアクション。
  • 普段と違う急な費用の増加に気づきたい → Cost Anomaly Detection。
  • どのサービス・アカウントに費用がかかっているかをグラフで見たい・来月の費用を予測したい → Cost Explorer。
  • リソース単位・時間単位の最も詳しい請求データをSQLで分析したい → CUR 2.0(S3+Athena)。
  • EC2のインスタンスタイプが大きすぎないかを知りたい → Compute Optimizer。メモリの使用率も考慮させるには、CloudWatchエージェントでメモリのメトリクスを送る。
  • 部署ごとの費用を出したい → タグを付けて、コスト配分タグとして有効化する。
  • Savings PlansやRIが十分に使われているか(使用率・カバレッジ)を見たい → Cost Explorerのレポート。下がったら通知するにはBudgetsの使用率予算。
  • 使っていない時間帯の費用を下げたい → 開発環境を夜間・休日に止める(ユースケース「開発環境を夜間・休日に自動で停止して費用を下げる」)。
  • 組織全体の費用をまとめたい → Organizationsの管理アカウントで一括請求。Savings PlansやRIの割引も組織内で共有される。

3. 関連サービス#

  • AWS Cost Explorer:費用の見える化と予測
  • AWS Cost and Usage Reports:詳細な請求データの出力
  • AWS Compute Optimizer:リソースのサイズの推奨
  • AWS Trusted Advisor:無駄なリソースのチェック
  • Savings Plans:長期利用の約束による割引
  • AWS Organizations:一括請求と割引の共有
  • Amazon EC2:リザーブドインスタンス・スポットインスタンス

この用語が出てくるページ#

  • AWS Compute Optimizerサービス機械学習でリソースの使用状況を分析し、最適な設定を推奨
  • AWS Cost ExplorerサービスAWSの料金と使用量をグラフで分析し、将来の費用を予測する
  • AWS Cost and Usage Reportsサービス最も詳細な料金・使用量のデータを、S3にファイルとして定期的に出力する
  • Savings Plansサービス1年または3年の利用額(1時間あたりの金額)を約束して、コンピューティングなどの料金を割り引く
