1. サービス概要#

AWS DataSyncは、オンプレミスとAWSの間、またはAWSのストレージサービス間でデータ転送を自動化・高速化するサービスです。

区分対応するストレージ
オンプレミス/自己管理NFS、SMB、HDFS、S3互換のオブジェクトストレージ
AWSS3、EFS、FSx
他クラウドGoogle Cloud Storage、Azure Blob Storageなど

2. 主な機能・特徴#

構成要素#

  • エージェント:オンプレミスのストレージに接続するために、VMware ESXi・KVM・Nutanix AHV・Hyper-Vの仮想マシンとして配置する(VPC内のストレージを対象にする場合は、Amazon EC2インスタンスとして配置する)。AWSのストレージ間の転送では不要。他クラウドとの転送は、エージェントを使う場合と使わない場合がある
  • ロケーション:転送元と転送先の定義
  • タスク:転送ジョブの定義(転送元・転送先・オプション・スケジュールをまとめる)

機能#

  • 増分転送:初回は全データ、2回目以降は変更分だけを転送
  • スケジュール実行:最短1時間間隔で、cron式かrate式を使って定期実行(曜日や時刻も指定できる)
  • 整合性の検証:転送中は常にチェックし、転送後に「転送したデータだけ」または「転送元と転送先の全体」を検証できる。差があると検証が失敗としてエラーになる
  • メタデータの扱い:メタデータ(権限など)と、転送元で削除されたファイルの扱いを設定で指定できる
  • 暗号化:転送中はTLSを使用

転送の流れ#

タスクを実行すると、DataSyncは準備・転送・検証の順に処理します。準備では転送元と転送先を比べ、変更された分だけを転送対象にします。すべてのデータを転送する設定にすると、比べずに全件を転送します。

タスクモード(BasicとEnhanced)#

タスクには、Basicモードと Enhancedモードの2つがあります。Enhancedモードは、一覧の取得・準備・転送・検証を並列に行うため、大量のファイルでも高い性能で扱えます。Basicモードは準備・転送・検証を順番に行い、扱える件数に上限があります。

項目EnhancedモードBasicモード
処理の進め方一覧の取得・準備・転送・検証を並列に行う準備・転送・検証を順番に行う
扱える件数(1回の実行あたり)実質無制限オンプレミスなどとの転送は5,000万件、AWSストレージ間は2,500万件まで
性能大半のワークロードで高いEnhancedモードより遅い

Basicモードの件数の上限に近い場合は、フィルターで対象のフォルダーを分けたタスクを作る方法もあります。NFS・SMB・HDFSとAWSストレージの間の転送には、Enhancedモード用のエージェントが必要です。

フィルターと帯域幅の制限#

フィルターで、転送するファイルやフォルダーを絞り込めます。含める(include)と除外する(exclude)を組み合わせて指定でき、変更は次回の実行から反映されます。帯域幅の上限は、タスクごとに設定できます。

開いているファイルとロックされたファイル#

転送中に書き込まれているファイルは、検証の段階で不整合として検出されます。最新の内容を転送するには、タスクをもう一度実行します。サーバーがロックしていて開けないファイルは、転送の途中でスキップされ、エラーとして記録されます。DataSyncがファイルをロックしたりロックを解除したりすることはありません。

ネットワーク接続#

  • パブリックエンドポイント:インターネット経由
  • VPCエンドポイント:Direct ConnectやSite-to-Site VPNと組み合わせ、インターネットを経由せずに転送

インターネットを通さない接続の組み合わせは用語ページ「オンプレミスとAWSをつなぐ方法の選び方」を参照してください。

3. ユースケース#

  • オンプレミスのファイルサーバー(NFS/SMB)からS3・EFS・FSxへのデータ移行
  • オンプレミスとAWSの間での定期的なデータ同期(増分転送)
  • リージョン間・ストレージサービス間のデータコピー
  • 他クラウドからAWSへのデータ移行

4. 料金の考え方#

転送したデータ量(GB単位)に応じて課金されます。転送先のストレージ料金や、リージョン間・インターネットへのデータ転送料金は別途かかります。

5. 関連サービス#

  • Amazon S3/Amazon EFS/Amazon FSx:転送先のAWSストレージ
  • Amazon VPC:VPCエンドポイントでのプライベート転送
  • AWS Direct Connect/AWS Site-to-Site VPN:オンプレミスとAWSをつなぐ回線
  • AWS Backup:転送後のバックアップ管理
  • AWS Storage Gateway:オンプレミスからAWSのストレージを使い続ける
  • 関連する用語:オンプレミスとAWSをつなぐ方法の選び方、VPCエンドポイント、保存時の暗号化と転送時の暗号化

6. 試験・実務でのポイント#

  • オンプレミスのNFS/SMBからAWSへオンラインでデータ移行・同期 → DataSync。
  • オンプレミスから転送するときはエージェントが必要。AWSストレージ間は不要。
  • インターネットを通さずに転送 → VPCエンドポイント+Direct Connect/VPN。
  • 2回目以降は増分転送。転送中は常に整合性をチェックし、転送後の検証も設定できる。
  • 一部のファイルだけを移す・除外する → フィルター(include/exclude)。
  • ネットワークの使用量を抑えたい → タスクに帯域幅の上限を設定する。
  • 定期的に同期したい → スケジュール実行(最短1時間間隔)。
  • 数千万件のファイルを移す → Enhancedモード(Basicモードは1回の実行で扱える件数に上限がある)。

7. まとめ#

  • DataSyncはエージェント・ロケーション・タスクで構成されるデータ転送サービス。
  • 増分転送・スケジュール・整合性検証・メタデータ保持に対応する。
