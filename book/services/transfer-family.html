AWS Transfer Family

SFTP・FTPS・AS2などでファイルをS3やEFSへ転送するマネージドサービス

最終更新:2026-11-07

内容の確認:2026年11月7日

1. サービス概要#

AWS Transfer Familyは、SFTP・FTPS・FTP・AS2やブラウザを使ったファイル転送をマネージドで提供するサービスです。転送先にAmazon S3またはAmazon EFSを使い、既存の利用者や取引先の転送手順を大きく変えずにAWSストレージと連携できます。

2. 主な機能・特徴#

プロトコルと保存先#

  • SFTP・FTPS・FTPで既存のファイル転送クライアントと接続する。
  • AS2で企業間のファイル連携を行う。
  • S3バケットまたはEFSファイルシステムへ直接転送する。
  • ユーザーごとにIAMロールやアクセス範囲を設定し、保存先のパスを制限する。

説明の中心 成功・推奨・正常 利用者・外部・送信元 その他の構成要素

後続処理との連携#

S3に届いたファイルは、S3イベント通知やEventBridgeを起点にLambda・Step Functions・Glueなどで処理できます。アップロード後のスキーマ確認、ウイルス検査、重複排除、隔離先への振り分けなどをパイプラインに含めます。

セキュリティと監視#

認証方式、ユーザーごとのIAMロール、VPC内外のエンドポイント、暗号化、アクセスログを構成します。転送プロトコルによってネットワークポートや接続条件が異なるため、取引先のファイアウォールと合わせて確認します。

3. ユースケース#

  • 取引先からSFTPやAS2で受け取るファイルをS3へ集約する。
  • 既存のファイル転送ワークフローを保ったまま保存先をAWSに移行する。
  • 顧客や社内ユーザーへS3内のファイルを安全に配布する。

4. 料金の考え方#

サーバーエンドポイントの稼働時間、転送量、プロトコル・機能の利用などに応じて料金が発生します。S3・EFSの保存とリクエスト、データ転送、後続処理の料金も考慮します。利用量や必要なプロトコル、公開範囲に応じて構成を選びます。

5. 関連サービス#

  • Amazon S3:ファイル転送先・データレイク
  • Amazon EFS:ファイルシステムの転送先
  • Amazon EventBridge:アップロード後のイベント処理
  • AWS Lambda/AWS Glue:後続の変換・処理
  • AWS CloudTrail:API操作の監査

6. 試験・実務でのポイント#

  • 既存のSFTP・FTPS・AS2ファイル連携をマネージド化 → AWS Transfer Family。
  • ファイル転送とデータベース移行は別の要件。データベース間の移行・CDCにはAWS DMSを検討する。
  • ユーザー単位のIAMロールとS3/EFSのアクセス範囲を最小権限にする。
  • ファイルが届いた後の検証・変換・分析は、イベント連携やETLサービスで構成する。

7. まとめ#

  • Transfer Familyは既存のファイル転送プロトコルをAWSストレージへ接続する。
  • S3/EFSへの保存、ユーザーごとのアクセス制御、後続処理を組み合わせる。
