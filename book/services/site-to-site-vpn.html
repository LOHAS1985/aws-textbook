AWS Site-to-Site VPN

オンプレミスとVPCを、インターネット上の暗号化トンネル(IPsec)でつなぐ

1. サービス概要

AWS Site-to-Site VPNは、オンプレミスのネットワークとAWSのVPCを、インターネット上の暗号化された通信路(IPsec VPN)で接続するサービスです。専用線を引かずに、数分〜数時間ですぐに使い始められます。

VPN(Virtual Private Network)は、共有のネットワークの上に、暗号化した仮想的な専用の通信路(トンネル)を作る技術です。

2. 主な機能・特徴

構成要素

要素内容
カスタマーゲートウェイデバイスオンプレミス側のVPNルーター(物理機器またはソフトウェア)
カスタマーゲートウェイ(CGW)オンプレミス側の機器の情報(パブリックIPアドレスなど)をAWSに登録したもの
仮想プライベートゲートウェイ(VGW)VPC側の終端。1つのVPCにアタッチする
Transit GatewayVGWの代わりの終端。多数のVPCとVPNをまとめて接続できる
VPN接続CGWとVGW(またはTGW)の間の接続。2本のトンネルを持つ

ルーティング

  • 静的ルーティング:オンプレミスのCIDRを手動で登録する。
  • 動的ルーティング(BGP):BGPで経路を自動で交換する。トンネルの切り替えも自動で行えるため推奨。
  • VPCのサブネットのルートテーブルでルート伝播を有効にすると、VGWが学習したオンプレミスの経路が自動で追加される。

そのほかの特徴

  • 帯域:1トンネルあたり最大1.25Gbps。それ以上が必要なら、Transit Gatewayで複数のVPN接続に分散する(ECMP)。
  • 高速化VPN(Accelerated VPN):Global Acceleratorのネットワークを経由して、通信を安定・高速にする(Transit Gatewayで利用)。
  • VPN CloudHub:1つのVGWに複数拠点のVPNをつなぎ、拠点同士も通信できるようにする。
  • Direct Connectのバックアップ:専用線が切れたときの予備の経路として使う。
  • 監視:CloudWatchの TunnelState(1=稼働、0=停止)や TunnelDataIn/TunnelDataOut を監視する。

AWS Client VPNとの違い

項目Site-to-Site VPNClient VPN
接続するもの拠点のネットワーク全体個人のPC(在宅勤務など)
接続元拠点のVPNルーターPCのVPNクライアントソフト(OpenVPNベース)

3. ユースケース

  • 社内ネットワークとVPCを、すぐに・安く接続する
  • Direct Connectを開通するまでの一時的な接続や、障害時のバックアップ
  • 複数の拠点をAWS経由で相互に接続する(VPN CloudHub)

4. 料金の考え方

VPN接続ごとの時間料金と、AWSからオンプレミスへのデータ転送(アウト)料金がかかります。Transit Gatewayを終端にする場合は、TGWのアタッチメント料金とデータ処理料金も加わります。

5. 関連サービス

  • Amazon VPC:接続先のネットワーク。VGWをアタッチする
  • AWS Transit Gateway:多数のVPCとVPNの終端を集約
  • AWS Direct Connect:専用線による接続。VPNはそのバックアップにもなる
  • AWS Global Accelerator:高速化VPNで使うネットワーク
  • Amazon CloudWatch:トンネルの状態の監視

6. 試験・実務でのポイント

  • 「すぐに」「低コストで」「暗号化して」オンプレミスと接続 → Site-to-Site VPN。「安定した帯域」「低レイテンシー」→ Direct Connect。
  • トンネルの停止を検知したい → CloudWatchの TunnelState にアラームを設定する。
  • VPN接続は確立したのに通信できない → サブネットのルートテーブル(ルート伝播)、セキュリティグループ、ネットワークACL、オンプレミス側のファイアウォールを確認する。
  • トンネルが1本しか使われていない・冗長化したい → 2本のトンネルを両方設定し、BGPで自動切り替えにする。
  • 1.25Gbpsを超える帯域が必要 → Transit Gateway+ECMP、またはDirect Connect。
  • Direct Connectの経路を暗号化したい → Direct Connectの上でSite-to-Site VPNを使う。

7. まとめ

  • インターネット上のIPsecトンネルで、オンプレミスとVPCを接続する。
  • CGW・VGW(またはTGW)・2本のトンネルで構成し、BGPでの動的ルーティングが推奨。
  • すぐ使えて安価。Direct Connectのバックアップにもなる。
  • 個人のPCから接続するのはClient VPN。
