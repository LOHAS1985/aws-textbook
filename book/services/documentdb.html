Amazon DocumentDB

MongoDB互換のドキュメントデータベースをマネージドで利用するサービス

最終更新:2026-11-07

内容の確認:2026年11月7日

1. サービス概要#

Amazon DocumentDBは、JSON形式のドキュメントを保存・検索するMongoDB互換のマネージドデータベースです。MongoDB用のドライバーやAPIを使うアプリケーションをAWS上で実行できます。

DocumentDBはMongoDBそのものではありません。APIの互換性や利用できる機能はエンジンのバージョンによって異なるため、移行前にアプリケーションが使うコマンド・集計機能・ドライバーを検証します。

2. 主な機能・特徴#

ドキュメントモデルとクラスター#

  • データを柔軟なJSON形式のドキュメントとして保存し、フィールドや配列を条件に検索する。
  • インスタンスベースのクラスターでは、書き込みを処理するインスタンスと読み取りレプリカを組み合わせる。
  • Elastic Clustersは、シャーディングによって水平にスケールするワークロード向けの選択肢。
  • ストレージはデータ量に応じて拡張され、バックアップや複数AZ構成を利用できる。

説明の中心 成功・推奨・正常 利用者・外部・送信元 その他の構成要素

データモデルの選択#

ドキュメント内のフィールドを柔軟に扱いたいときや、MongoDB互換アプリを移行するときに候補になります。関係データやトランザクションをSQLで扱う場合はAmazon RDS、キーを指定した低遅延アクセスはAmazon DynamoDBと比較します。

3. ユースケース#

  • MongoDB互換のアプリケーションをAWSへ移行する。
  • 商品カタログやユーザープロファイルなど、属性が異なるドキュメントを保存する。
  • JSON形式のデータをアプリケーションの読み書きに合わせて検索する。

4. 料金の考え方#

クラスターのインスタンスやElastic Clustersの処理能力、データストレージ、バックアップ、データ転送などが料金に影響します。必要な読み取り性能、冗長性、保持期間を見積もり、クラスター構成を調整します。

  • AWS DMS:データベース移行と継続レプリケーション
  • AWS Backup:データベースのバックアップ管理
  • AWS KMS:暗号化キーの管理
  • 関連する用語:データストアの選び方

6. 試験・実務でのポイント#

  • MongoDB互換のドキュメントデータベース → Amazon DocumentDB。
  • MongoDBとの機能互換性を前提にせず、アプリが使うAPI・ドライバー・クエリーを移行前に確認する。
  • 関係データのSQLクエリーやトランザクションが必要なら、RDS・Auroraとの要件を比較する。

7. まとめ#

  • DocumentDBはMongoDB互換のドキュメントデータベース。
  • データモデルとAPI互換性を確かめて、適切なクラスター方式を選ぶ。
