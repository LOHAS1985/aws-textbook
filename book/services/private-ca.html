AWS Private CA

組織内で使うプライベート証明書を発行する認証局

1. サービス概要

AWS Private CA(Private Certificate Authority)は、組織内だけで使うプライベート証明書を発行するための認証局(CA)をマネージドで提供するサービスです。インターネットに公開しない社内システムや、サービス間の通信の認証に使います。

2. 主な機能・特徴

  • ルートCA・下位CAの階層を作成・運用できる。CAの秘密鍵はAWSが管理するHSMで保護される。
  • ACMと連携し、プライベート証明書をALBなどに配置したり、自動更新したりできる。
  • 証明書失効リスト(CRL)やOCSPによる失効管理に対応。
  • 相互TLS(mTLS)で、クライアント側も証明書で認証できる。

3. ユースケース

  • 社内向けWebサイト・APIのHTTPS化
  • マイクロサービス間・IoTデバイスのmTLS認証
  • オンプレミスの自前CAの運用負荷をなくしたい

4. 料金の考え方

CAごとの月額料金と、発行した証明書の枚数に応じて課金されます。ACMのパブリック証明書(無料)と違い、有料です。

5. 関連サービス

  • AWS Certificate Manager:パブリック証明書の発行、プライベート証明書の配布
  • Elastic Load Balancing:証明書の配置先

6. 試験・実務でのポイント

  • インターネットに公開しない社内向けの証明書 → Private CA。
  • 公開Webサイトの証明書 → ACMのパブリック証明書(無料)。

7. まとめ

  • Private CAは組織内向けのプライベート証明書を発行するマネージドCA。
