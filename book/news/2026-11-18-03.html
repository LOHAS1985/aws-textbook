API Gateway:REST API が JWT オーソライザーに対応

API Gateway の REST API に、コードを書かずにトークンを検証できる JWT オーソライザーが追加されました。

最終更新:2026-11-18

1. 発表の内容#

JWT(JSON Web Token)は、利用者の身元や権限を署名つきで表すトークンです。API Gateway の REST API で Amazon Cognito 以外の ID プロバイダー(OpenID Connect や OAuth 2.0 に対応したもの)のトークンを検証するには、これまで Lambda オーソライザー(検証用の Lambda 関数)を自分で書いて運用する必要がありました。

今回、API Gateway 自体がトークンを検証する JWT オーソライザーが追加されました。発行元(issuer)、受け付ける audience、許可する署名アルゴリズムなどを設定するだけで、リクエストごとに署名・発行元・有効期限・クレーム(トークンに含まれる情報)が検証されます。1つのオーソライザーを複数のメソッドに付け、メソッドごとに必要なスコープを変えることもできます。リージョン、エッジ最適化、プライベートのどの REST API でも使えます。

説明の中心 成功・推奨・正常 利用者・外部・送信元 その他の構成要素

何がうれしいか
認証用のコードと Lambda 関数の運用が不要になり、設定だけで外部の ID プロバイダーに対応できます。
試験・実務への影響
API の認証方式(IAM 認可、Cognito、Lambda オーソライザー)の使い分けは定番の出題です。JWT オーソライザーという選択肢が REST API にも加わったと押さえておきましょう。
