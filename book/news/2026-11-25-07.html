FSx for NetApp ONTAP:スナップショット・クローン・レプリケーションをコンソールと CloudFormation で管理

FSx for ONTAP のスナップショット、ボリュームのクローン、SnapMirror レプリケーションを、FSx コンソール・API・CloudFormation から操作できるようになりました。

最終更新:2026-11-25

1. 発表の内容#

これまで ONTAP の CLI や REST API でしか設定できなかったスナップショット、ボリュームのクローン、SnapMirror によるレプリケーションを、Amazon FSx のコンソール・API・CloudFormation からも管理できるようになりました。ほかの AWS リソースと同じ道具で、インフラをコードとして扱えます。FSx for ONTAP が使えるすべてのリージョンで利用できます。
