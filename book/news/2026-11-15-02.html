Aurora PostgreSQL:express configuration を CloudFormation で作成可能に

Aurora PostgreSQL の express configuration(数秒で作れる簡易構成)を、CloudFormation のテンプレートから1つの項目で作れるようになりました。

最終更新:2026-11-15

1. 発表の内容#

Aurora PostgreSQL の express configuration は、サーバーレスのデータベースを数秒で作って、すぐに使い始められる作成方法です。今回、これを AWS CloudFormation(テンプレートでインフラを自動作成するサービス)から使えるようになりました。

AWS::RDS::DBCluster リソースに、作成時だけ指定できる withExpressConfiguration というプロパティが加わりました。これを指定すると、クラスターと最初のDBインスタンスが一度に作られます。これまでのようにインスタンスを別のリソースとして書いて管理する必要がなく、テンプレートが短くなります。

説明の中心 成功・推奨・正常 その他の構成要素

何がうれしいか
手早く作れる express configuration を、コンソールだけでなくコードで繰り返し再現できます。テンプレートも単純になります。
試験・実務への影響
データベースを手作業ではなくテンプレートで作るのは、運用の基本です。Aurora もCloudFormationで構築できる、という流れで押さえておきましょう。
