WAF と API Gateway:API を自動で見つけて守る API Portal と API Security

API Gateway の API Portal が組織内の API を自動で洗い出し、AWS WAF の API Security ルールグループで、見つかった API を守れるようになりました。

最終更新:2026-11-25

1. 発表の内容#

API Gateway に「API Portal」が加わりました。Amazon API Gateway、Application Load Balancer、CloudFront の背後にある API を、AWS 側のトラフィックログと構成の記録から、AWS 組織全体で自動的に見つけます。エージェントの導入やログの転送は要りません。見つけた API は、管理対象にするまでは「シャドー API」(把握されていない API)として扱われ、公開か非公開かの分類、使われなくなったゾンビ API の検出、認証・スロットリング・WAF の有無といったセキュリティ状況の評価も行われます。

WAF で守っていない API には、新しい「API Security」マネージドルールグループを使えます。他人のデータの ID に書き換えて読み取る BOLA、偽造トークンや盗んだパスワードを使う認証の突破、隠れたルートを探る偵察といった代表的な攻撃を、カスタムルールを書かずに防ぎます。検知したイベントは API Portal の結果にまとまります。

説明の中心 成功・推奨・正常 失敗・非推奨・障害 利用者・外部・送信元

何がうれしいか
誰も把握していない API や放置された API を洗い出し、WAF の保護漏れまで一画面で確認できます。ルールを自作せずに、API への主要な攻撃を防げます。
試験・実務への影響
公開している API の棚卸しと WAF の適用は、セキュリティ運用の基本です。API Portal は32のリージョンで提供され、既存の API Gateway のポータルは「Documentation Portals」の項目から引き続き管理できます。
