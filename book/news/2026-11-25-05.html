WAF:LLM・MCP・A2A のエンドポイントを自動で見つけて守る AI Security

API Portal が AI のエンドポイントも見つけ、WAF の AI Security ルールグループが Bedrock Guardrails でプロンプトインジェクションなどを検査します。

最終更新:2026-11-25

1. 発表の内容#

API Portal が見つける対象に、LLM・MCP・A2A のエンドポイント(AI モデルやエージェントが外部から呼ばれる入口)が加わりました。非公開のはずの MCP サーバーが公開されていれば、シャドー API として現れます。保護には、新しい WAF の「AI Security」マネージドルールグループを使います。MCP と A2A のメッセージの形式チェックに加え、コンテンツ検査を有効にすると Amazon Bedrock Guardrails を呼び出して、プロンプトインジェクションや有害な内容、応答に含まれる機密情報を検出します。追加料金がかかり、Bedrock の検査呼び出しは別に課金されます。
