Route 53 Profiles:1つのVPCに複数のProfileを関連付け

1つのVPCに複数のRoute 53 Profileを優先順位つきで関連付けられるようになり、チームごとにDNS設定を分けて管理できます。

最終更新:2026-11-11

1. 発表の内容#

Route 53 Profiles は、プライベートホストゾーン、Resolver の転送ルール、DNS Firewall のルールグループなどのDNS関連の設定を1つにまとめ、複数のVPCに共有する仕組みです。これまでは1つのVPCに関連付けられる Profile は1つだけで、セキュリティチームとネットワークチームの設定を同じ Profile に入れる必要がありました。今回、1つのVPCに複数の Profile を関連付けられるようになりました。各 Profile には優先順位を付け、番号の小さいものから評価されます。例えばセキュリティチームは DNS Firewall の Profile を、ネットワークチームはプライベートホストゾーンと転送ルールの Profile を、それぞれ自分で管理できます。

説明の中心 成功・推奨・正常 利用者・外部・送信元

何がうれしいか
設定の持ち主ごとに Profile を分けられるので、IAM の権限も最小限に絞りやすく、他のチームの設定を壊す心配が減ります。
試験・実務への影響
多数のVPCやアカウントでDNS設定を共通化する構成の設計で、役割分担をどう分けるかの選択肢が増えます。Profile とVPCの関連付けは、通常のRoute 53 Profiles の料金で課金されます。Profiles が使えるリージョンで利用できます。
