Config:マネージド適合パックを提供

AWS Config が、PCI DSS や SOC 2 などの基準ごとに AWS が作って更新し続ける適合パックを提供し、テンプレートの自前管理が不要になりました。

最終更新:2026-11-19

1. 発表の内容#

AWS Config は、リソースの設定がルールに合っているかを継続的に評価するサービスです。適合パック(複数の Config ルールをまとめた、コンプライアンス用のセット)は、これまでサンプルのテンプレートを自分の環境に合わせて直し、ルールが増えたり基準が改訂されたりするたびに自分で更新する必要がありました。

新しいマネージド適合パックは、AWS が基準ごとに作成・保守するパックです。基準を選んで展開するだけで評価が始まり、対応する新しいマネージドルールが出たり基準が改訂されたりすると、展開済みのパックが自動で更新されます。どのリージョンでも同じ定義で使え、ルールのパラメータは環境に合わせて変えられます。評価結果とコンプライアンススコアは Config のコンソールに他のルールと並んで表示されます。

説明の中心 成功・推奨・正常 利用者・外部・送信元 その他の構成要素

何がうれしいか
基準の改訂やルール追加を追いかける手間がなくなり、リージョンごとのテンプレート管理も不要になります。
試験・実務への影響
セキュリティ・コンプライアンスの分野では、Config ルールと適合パックによる継続的な準拠確認が頻出です。自前で作る方式と、AWS が保守するマネージドの方式の違いを押さえましょう。
