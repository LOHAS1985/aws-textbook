分析

AWS Glue DataBrew

コードを書かずにデータを調査・整形するビジュアルなデータ準備ツール

1. サービス概要#

AWS Glue DataBrewは、データを画面上で調査・プロファイルし、コードを書かずに整形・標準化するデータ準備ツールです。操作をレシピとして保存し、データセットに繰り返し適用できます。

2. 主な機能・特徴#

プロファイルと変換レシピ#

  • データの値の分布や欠損、型の不整合をプロファイルで確認する。
  • 画面で選んだ変換をレシピとして記録し、プレビューを見ながら順序を調整する。
  • 欠損値・異常値の処理、形式統一、列の分割・結合などの変換を行う。
  • 作成したレシピをジョブとして実行し、処理済みデータをS3などへ出力する。

説明の中心 成功・推奨・正常 利用者・外部・送信元 その他の構成要素

Glueとの連携#

DataBrewはビジュアルな探索・準備を行うAWS Glueの機能です。複雑な分岐や大規模な処理をコードで管理する場合はAWS Glue ETLジョブを使い、品質評価ルールを自動実行する場合はGlue Data Qualityを組み合わせます。

3. ユースケース#

  • 分析担当者がCSVやデータレイクの値を調査して、欠損・不正値を見つける。
  • 異なる形式の日付やカテゴリ値を統一し、分析用データを作る。
  • レシピを定期ジョブとして実行し、同じ変換を再利用する。

4. 料金の考え方#

プロジェクトやレシピジョブの実行など、利用する機能と処理量に応じて課金されます。S3の保存料金や、出力先の分析サービスの料金も考慮します。プロファイルの対象データ量やジョブの実行頻度を調整します。

  • Amazon Athena:準備済みデータのSQL分析
  • Amazon Redshift:準備済みデータの分析
  • 関連する用語:データ品質

6. 試験・実務でのポイント#

  • コードを書かずにデータを可視化・整形し、レシピを再利用 → AWS Glue DataBrew。
  • プロファイルはデータの傾向を理解するもの、品質ルールは合否基準を継続的に検査するもの。
  • 変換のプレビューだけでなく、ジョブ出力のスキーマ・件数・品質を確認する。

7. まとめ#

  • DataBrewは画面操作でデータを探索・整形するAWS Glueのツール。
  • 変換手順をレシピに保存し、ジョブで繰り返し実行できる。
設計・運用

データ品質

分析や業務処理に使えるデータかをルールと測定値で確かめる考え方

1. 詳しい説明#

データ品質は、データが利用目的に対して正しく、完全で、一貫しているかを継続的に確認することです。取り込み時や変換後にルールを評価し、失敗したデータを特定して修正・隔離します。

品質の観点#

  • 完全性:必須項目が欠損していないか。
  • 一意性:同じ業務キーの重複がないか。
  • 妥当性:値が型・範囲・形式などのルールに合うか。
  • 正確性・一貫性:参照元と一致し、複数項目やテーブル間で矛盾しないか。
  • 適時性:必要な時間までにデータが届き、十分に新しいか。

ルール・プロファイル・サンプリング#

AWS Glue Data Qualityは、ルールに基づいてカタログテーブルやETL結果を評価し、結果を記録できます。AWS Glue DataBrewではデータのプロファイルを確認し、変換レシピを作れます。サンプリングは全件処理を避けて傾向を素早く確認できますが、稀な異常や偏りを見落とす可能性があります。全件検証と代表サンプルの目的を分けます。

データスキューと集計#

データスキューは、キーの値によりレコード数や処理負荷が一部のパーティションに偏る状態です。ホットキーがあると、他のワーカーが空いていても特定タスクが遅れます。キー分布、パーティション、処理時間を調べ、必要に応じてキー設計や処理方法を変えます。

集計ではグループ化・合計・件数・移動平均・ピボットなどを利用します。集計の粒度、タイムゾーン、重複排除、NULLの扱いを決め、結果の合計値や件数を既知の値と照合します。

説明の中心 成功・推奨・正常 失敗・非推奨・障害 利用者・外部・送信元
