Amazon AppFlow

SaaSアプリケーションとAWSの間でデータを転送するマネージド連携サービス

最終更新:2026-11-07

内容の確認:2026年11月7日

1. サービス概要#

Amazon AppFlowは、SalesforceなどのSaaSアプリケーションとAmazon S3・Amazon Redshiftなどの間でデータを安全に転送するマネージドサービスです。コードを書かずにフローを定義し、手動・スケジュール・イベントを契機に実行できます。

2. 主な機能・特徴#

フローの設定#

  • ソースと宛先、対象オブジェクト・項目、実行条件を指定する。
  • フィールドの対応付け、フィルター、簡単な変換を設定する。
  • 一括転送だけでなく、変更されたレコードを定期的に同期する構成も選べる。
  • S3への出力をパーティション分割し、Glue Data Catalogに登録して分析サービスから検索しやすくできる。

セキュリティと監視#

転送中と保存時のデータ暗号化に対応し、AWS PrivateLinkを使ってプライベートに転送できる接続先もあります。すべてのコネクターや転送先で同じ接続方式が使えるわけではないため、要件とコネクターの対応状況を確認します。API操作はCloudTrailで監査できます。

3. ユースケース#

  • Salesforceの顧客・商談情報を定期的にS3へ集めて分析する。
  • 業務SaaSのレコードをRedshiftへ取り込み、BIレポートに使う。
  • 複数のSaaSアプリケーションからデータを集約し、データレイクを作る。

4. 料金の考え方#

フローの実行回数や処理したデータ量などに応じて料金が発生します。接続先SaaSのAPI利用制限や契約条件、S3・Redshiftの保存・処理料金も考慮します。頻繁な同期が必要か、定期的な一括取り込みでよいかを見極めます。

5. 関連サービス#

  • Amazon S3:転送データの保存とデータレイク
  • Amazon Redshift:分析用データウェアハウス
  • AWS Glue:カタログ化と複雑なETL
  • AWS CloudTrail:フローの操作履歴の監査
  • Amazon VPC:PrivateLinkを使う接続の基盤

6. 試験・実務でのポイント#

  • SaaSアプリケーションからAWSへコードを書かずに転送 → Amazon AppFlow。
  • 複雑な変換・大規模な統合処理にはGlueなどを組み合わせる。
  • スケジュール実行かイベント駆動かを、データの鮮度とSaaS側API制限に合わせて選ぶ。
  • 外部SaaSへの接続と、AWS内の転送先権限の両方を確認する。

7. まとめ#

  • AppFlowはSaaSとAWSのデータ連携をフローとして設定する。
  • S3やRedshiftを宛先にでき、スケジュール・イベントによる転送が可能。
