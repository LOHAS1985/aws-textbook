AWS Cost Explorer

AWSの料金と使用量をグラフで分析し、将来の費用を予測する

最終更新:2026-10-26

1. サービス概要#

AWS Cost Explorerは、AWSの料金と使用量をグラフや表で見て分析するツールです。サービス別・アカウント別・タグ別などに分けて、「何にいくらかかっているか」「いつから増えたか」を調べられます。過去の実績から将来の費用の予測も表示します。

画面での利用は無料です。一度有効にすると無効にはできません。

2. 主な機能・特徴#

見られるデータの範囲#

  • 有効にすると、当月と過去13か月分のデータが用意され、今後18か月分の予測が計算される。
  • データは少なくとも24時間に1回更新される(リアルタイムではない)。
  • 粒度は月・日。時間単位は管理アカウントで有効にすると直近14日分が見られる(有料)。
  • 予測は80%の予測区間で示され、利用期間が1請求期間に満たないアカウントでは表示されないことがある。

分析の軸(グループ化・フィルター)#

軸例
サービスEC2・S3・RDSのどれが高いか
連結アカウントOrganizationsの一括請求で、どのアカウントが使っているか
リージョン・AZどのリージョンの費用か
使用タイプ・API操作データ転送・NATゲートウェイの処理量など、費用の中身
コスト配分タグプロジェクト・部署・環境ごとの費用
購入オプションオンデマンド・リザーブド・Savings Plans・スポットの内訳

タグで費用を分けるには、請求コンソールでそのタグをコスト配分タグとして有効化しておく必要があります。有効化した後に発生した費用から反映されます。

リザーブドインスタンス・Savings Plansのレポート#

  • 推奨事項:過去の使用量から、購入すると得になるRI・Savings Plansの種類と量を示す。
  • 使用率:購入したRI・Savings Plansを、どれだけ使い切っているか。
  • カバレッジ:使用量のうち、RI・Savings Plansで割り引かれている割合。

Cost Management のほかの機能との違い#

機能役割
Cost Explorer費用を見て分析する・予測する
AWS Budgets予算を決め、超えそうなとき(予測を含む)に通知や自動のアクションを行う
Cost Anomaly Detection機械学習で、いつもと違う費用の増え方を検出して通知する
Cost and Usage Reports(Data Exports)最も細かい請求データをS3にファイルで出力する

3. ユースケース#

  • 先月から費用が急に増えた原因を、サービス→使用タイプ→リソースの順に絞り込む
  • コスト配分タグでプロジェクトごとの費用を出し、部署に配賦する
  • 予測を見て、年度末までの費用の見込みを立てる
  • RI・Savings Plansの購入量を推奨事項で決め、使用率とカバレッジで効果を確認する

4. 料金の考え方#

コンソールでの利用は無料です。Cost Explorer API はリクエストごとに課金され、時間単位・リソース単位のデータを有効にすると追加の料金がかかります。

5. 関連サービス#

  • AWS Cost and Usage Reports:詳細な請求データの出力
  • Savings Plans:購入の推奨・使用率・カバレッジの確認
  • AWS Organizations:一括請求とアカウント別の分析
  • AWS Compute Optimizer:リソースのサイズの最適化
  • AWS Trusted Advisor:使われていないリソースなどのコストの指摘
  • 関連する用語:料金の基本、タグ

6. 試験・実務でのポイント#

  • 「費用の内訳をグラフで分析」「将来の費用の予測」→ Cost Explorer。
  • タグ別に費用が出ない → コスト配分タグを有効化していない(有効化前の費用には付かない)。
  • 予算超過の通知は AWS Budgets、異常な増え方の検出は Cost Anomaly Detection。
  • 最も細かいデータをAthenaなどで分析したいなら CUR(Data Exports)。
  • RI・Savings Plansの使用率(買った分を使えているか)とカバレッジ(どれだけ割引されているか)を区別する。
  • Cost Explorer・Budgets・CUR・Compute Optimizerの使い分け → コスト管理ツールの選び方。

7. まとめ#

  • Cost Explorerは、料金と使用量を軸ごとに分けて分析し、将来の費用を予測するツール。
  • RI・Savings Plansの推奨と効果の確認にも使う。

このサービスが登場する運用シナリオ#

  • 開発環境を夜間・休日に自動で停止して費用を下げる
  • プライベートサブネットからNATなしでAWSのサービスを使う
