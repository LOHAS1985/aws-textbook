AWS Database Encryption SDK

アプリ側でDBのデータを暗号化・復号するライブラリ

1. サービス概要

AWS Database Encryption SDKは、アプリケーション側でデータベースのデータを暗号化・復号するライブラリです(クライアント側暗号化)。主にDynamoDB用です。

※サーバー側の暗号化には、KMSキーを使ったDBテーブルの暗号化を使います。

2. 主な機能・特徴

暗号化の流れ

  1. AWS KMSを使ってデータキーを生成
  2. データキーでデータを暗号化
  3. データキーをKMSで暗号化
  4. 次の情報をDynamoDBに保存
    • 暗号化データ
    • 暗号化されたデータキー
    • メタデータ

この流れはKMSのエンベロープ暗号化と同じ考え方です。属性(カラム)ごとに「暗号化する/署名のみ/何もしない」を選べるため、検索に使うキーは暗号化せずに、機密な属性だけを暗号化できます。また、データに署名を付けて改ざんを検知できます。

3. ユースケース

  • DynamoDBに保存する個人情報やカード番号などを、アプリ側で暗号化してから保存したい
  • DB管理者やAWS側からも平文が見えないようにしたい(エンドツーエンドの保護)

4. 料金の考え方

ライブラリ自体は無料です。データキーの生成・復号に使うKMSのAPIリクエストとキーの料金がかかります。

5. 関連サービス

  • Amazon DynamoDB:主な対象データベース
  • AWS KMS:データキーの生成・暗号化
  • AWS SDK:アプリからのAWS操作

6. 試験・実務でのポイント

  • DynamoDBのデータをアプリ側(クライアント側)で暗号化 → Database Encryption SDK。
  • サーバー側(保存時)の暗号化 → KMSキーによるテーブルの暗号化。
  • 保存されるのは「暗号化データ+暗号化されたデータキー+メタデータ」。

7. まとめ

  • Database Encryption SDKは、KMSのデータキーを使ってアプリ側でDBのデータを暗号化するライブラリ。
