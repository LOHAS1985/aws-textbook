AWS SDK

アプリからAWSサービスを操作するための公式ライブラリ群

最終更新:2026-10-26

1. サービス概要#

AWS SDK(Software Development Kit)は、アプリケーションからAWSサービスを操作するための公式ライブラリ群です。REST APIを直接呼ぶ代わりに、SDKのメソッドを使います。

2. 主な機能・特徴#

  • プログラムからAWSを操作するには認証情報(IAMユーザーのアクセスキーなど)が必要。

実務では、アクセスキーをコードに書くのではなく、EC2のインスタンスプロファイルやLambdaの実行ロールなどIAMロールの一時認証情報を使うのが推奨です。SDKは決められた優先順位で認証情報を自動的に探します(AWS IAMの「認証情報の優先順位」を参照)。

対応言語#

  • Java:AWS SDK for Java
  • JavaScript:AWS SDK for JavaScript
  • Python:Boto3(Python用の公式SDK)
  • .NET、Go(AWS SDK for Go)、Ruby、PHPなど

メソッドの例(Python)#

# S3:オブジェクトのアップロード
s3.put_object(Bucket="my-bucket", Key="sample.txt", Body="hello")

# DynamoDB:アイテムの登録
table.put_item(Item={"userId": "u001", "name": "Taro"})

クライアントの初期化#

AWSサービスへアクセスするためのオブジェクトを生成・設定します。Lambdaではハンドラーの外で初期化すると、実行環境が再利用されたときに毎回初期化しなくて済みます。

import boto3

# ハンドラー外で初期化
s3 = boto3.client('s3')

def lambda_handler(event, context):
    response = s3.list_buckets()
    return response

3. ユースケース#

  • アプリからS3へのファイルアップロード、DynamoDBへの読み書き
  • Lambda関数内から他のAWSサービスを呼び出す
  • 運用スクリプトでのリソース操作の自動化

4. 料金の考え方#

SDK自体は無料です。SDKから呼び出したAWSサービスの料金がかかります。

5. 関連サービス#

  • AWS IAM:認証情報と優先順位
  • AWS Lambda:ハンドラー外での初期化
  • Amazon S3/Amazon DynamoDB:よく操作されるサービス
  • AWS X-Ray:SDKの呼び出しのトレース
  • 関連する用語:スロットリングとリトライ、IAMロールと一時的な認証情報、AWSの操作方法

6. 試験・実務でのポイント#

  • PythonのSDK → Boto3。
  • Lambdaでは、SDKクライアントやDB接続をハンドラーの外で初期化して再利用する。
  • 認証情報はコードに書かず、IAMロールを使う。

7. まとめ#

  • AWS SDKは各言語向けのAWS操作ライブラリ。Lambdaではクライアントをハンドラー外で初期化する。
