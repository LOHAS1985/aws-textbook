Amazon Q

業務データに基づく回答やAWS開発支援を提供する生成AIアシスタント群

最終更新:2026-11-07

内容の確認:2026年11月7日

1. サービス概要#

Amazon Qは、業務データに基づく回答を行うAmazon Q Businessと、AWSやソフトウェア開発を支援するAmazon Q Developerなどの生成AIアシスタント群です。用途に応じて、データソース・利用者・アクセス権を分けて考えます。

Amazon Q Businessは新規顧客の利用開始が終了しており、AWSは類似機能の後継としてAmazon Quickを案内しています。Amazon Q DeveloperはIDEやCLIでの開発支援として提供されています。コンソール上の会話型アシスタントはAWS assistantへ移行しているため、現行の名称と提供状況を確認します。

2. 主な機能・特徴#

用途の異なるアシスタント#

  • Q Business:企業データソースと連携し、利用者の権限に応じた回答・要約・検索を行う。新規顧客は利用できない。
  • Q Developer:コードやAWSサービスについて質問し、IDEやCLIで開発作業を支援する。
  • Amazon Quick:Q Businessに類似する業務アシスタントに加えて、BIやエージェント機能を提供する現行の選択肢。

Q Businessで使われるデータ連携や権限付き検索の考え方はデータエンジニアリングに関係しますが、Amazon Q自体はデータウェアハウスやETLサービスではありません。

3. ユースケース#

  • 既存のQ Business環境で、アクセス権を考慮した社内情報の検索を行う。
  • Q Developerを使って、AWSやアプリケーションの開発作業を支援する。
  • 新規の業務データ活用ではAmazon Quickなど現行サービスを評価する。

4. 料金の考え方#

Amazon Qの製品・契約プラン、利用者数、機能に応じて料金が異なります。Q Businessの既存利用と、Amazon QuickやQ Developerの新規利用を分けて、最新の料金ページで確認します。

5. 関連サービス#

  • Amazon Quick:Q Businessに類似する現行の業務アシスタントとBI
  • Amazon Kendra:既存環境の企業検索
  • Amazon Bedrock:生成AIアプリケーションの基盤
  • Amazon S3:企業データの保存先
  • 関連する用語:データガバナンス、ベクトル検索

6. 試験・実務でのポイント#

  • 企業データを使う業務支援と開発支援を区別し、用途に合うAmazon Q製品を選ぶ。
  • Q Businessは新規顧客の利用開始が終了している。新規構成ではAmazon Quickなど現行の選択肢を確認する。
  • Amazon QはETLやデータベースではない。データ連携・検索・生成AIによる利用者支援を担う。

7. まとめ#

  • Amazon Qには企業データ向けと開発者向けの異なるアシスタントがある。
  • Q Businessの提供状況が変更されているため、新規利用では現行のAmazon Quickなどを確認する。
