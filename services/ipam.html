Amazon VPC IP Address Manager (IPAM)

組織全体のVPCのIPアドレスを計画・割り当て・監視し、CIDRの重複を防ぐ

最終更新:2026-10-25

1. サービス概要#

Amazon VPC IP Address Manager(IPAM)は、複数のアカウント・リージョンにまたがるIPアドレス(CIDR)を一元的に計画・割り当て・監視するVPCの機能です。

VPCが増えると、表計算ソフトでのCIDRの管理では重複や記入漏れが起きがちです。CIDRが重なったVPCどうしはピアリングやTransit Gatewayでうまくつなげません。IPAMを使うと、決められた範囲から重ならないCIDRを自動で割り当てられます。

2. 主な機能・特徴#

構成要素#

要素説明
IPAM本体。管理するリージョン(運用リージョン)を指定する
スコープIPアドレス空間の単位。プライベートスコープとパブリックスコープが最初から作られる
プールCIDRの集まり。入れ子にして階層を作れる(例:全社 → リージョン → 本番/開発)
割り当てルールプールから割り当てるCIDRのサイズの上限・下限・既定値、必須のタグなど

主な機能#

  • CIDRの自動割り当て:VPCの作成時にIPAMプールを指定すると、空いているCIDRが割り当てられる。CloudFormationからも指定できる。
  • 使用状況の監視:プールやVPCのIPアドレスの使用率を確認し、CloudWatchでアラームを設定できる。
  • 重複・非準拠の検出:CIDRが重なっているリソースや、割り当てルールに合わないリソースを見つける。
  • IPアドレスの履歴:あるIPアドレスが、いつどのリソースに使われていたかを調べられる(セキュリティ調査に便利)。
  • パブリックIPの分析:パブリックIPv4アドレスの使い道(EC2・NAT・ELBなど)を一覧にする。
  • 独自に保有するIPアドレス(BYOIP)やIPv6アドレスの管理。

複数アカウントでの利用#

Organizations と連携し、委任管理者アカウントでIPAMを作成します。プールは AWS RAM で他のアカウントに共有し、各アカウントはそのプールからCIDRを割り当てます。

ティア#

無料ティアと高度なティアがあります。無料ティアで使えるのはパブリックIPの分析など一部の機能だけです。プライベートIPアドレスのプールを作る場合や、IPAMを所有するアカウント以外にCIDRを割り当てる場合は、高度なティアが必要です。

3. ユースケース#

  • 大規模な組織で、全VPCのCIDRが重ならないように自動で割り当てる
  • Transit Gatewayやオンプレミスと接続する前に、CIDRの重複がないか確認する
  • IPアドレスの枯渇を、使用率のアラームで事前に知る
  • 使われていないパブリックIPv4アドレス(Elastic IP)を見つけて費用を減らす

4. 料金の考え方#

高度なティアでは、IPAMで管理しているアクティブなIPアドレスの数に応じた時間料金がかかります。無料ティアは無料です。

5. 関連サービス#

  • Amazon VPC:CIDRを割り当てる対象
  • AWS Organizations/AWS RAM:委任管理者とプールの共有
  • AWS Transit Gateway:CIDRが重ならないことが前提の接続
  • Amazon CloudWatch:使用率のアラーム
  • CIDR

6. 試験・実務でのポイント#

  • 「複数アカウントのVPCのCIDRの重複を防ぐ」「IPアドレスの一元管理」→ IPAM。
  • 他のアカウントへのプールの共有は RAM、組織での管理は委任管理者。
  • IPアドレスの使用率は CloudWatch のメトリクスでアラームにできる。

7. まとめ#

  • IPAMは、組織全体のIPアドレスをプールの階層で管理し、重ならないCIDRを自動で割り当てる。
  • 使用状況・重複・IPアドレスの履歴を確認できる。

このサービスが登場する運用シナリオ#

  • 組織全体のVPCのIPアドレスを重ならないように払い出す
