Amazon Bedrock

複数の企業の生成AIモデル(基盤モデル)を、1つのAPIでサーバーの管理なしに使える

最終更新:2026-10-25

1. サービス概要#

Amazon Bedrockは、Anthropic(Claude)・Amazon(Nova)・Meta(Llama)・Mistral AI など複数の企業の生成AIモデル(基盤モデル)を、共通のAPIで使えるフルマネージドサービスです。GPUサーバーを用意したり、モデルを動かす基盤を管理したりする必要はありません。

入力したデータや出力は、モデルの学習には使われません。社内文書を参照させる仕組み(RAG)や、有害な出力を防ぐ仕組みなど、業務のアプリに組み込むための機能もそろっています。

2. 主な機能・特徴#

機能内容
モデルの呼び出しInvokeModel や、モデルの違いを吸収した Converse APIで、テキスト・画像などを入力して結果を受け取る。ストリーミングにも対応
ナレッジベースS3などの社内文書をベクトル化して保存し、質問に関連する部分を探してモデルに渡す(RAG:検索拡張生成)
ガードレール有害な内容・禁止したい話題・個人情報(PII)の入出力をフィルタリングする
エージェント/AgentCoreモデルがAPIやツールを呼び出しながら作業を進めるAIエージェントを作り、動かす
モデルのカスタマイズ自社のデータでモデルを追加学習(ファインチューニングなど)する
モデルの評価複数のモデルの回答の品質を比べる

運用で押さえること#

  • モデル呼び出しのログ:入力・出力の内容を記録するには、モデル呼び出しのログを有効にして CloudWatch Logs や S3 に出力する(既定では無効)。APIの呼び出し自体は CloudTrail に記録される。
  • メトリクス:CloudWatch で呼び出し回数・レイテンシー・スロットリングの回数・入出力のトークン数などを監視できる。
  • クォータとスロットリング:モデルごとに1分あたりのリクエスト数・トークン数の上限がある。超えると ThrottlingException になるので、再試行(エクスポネンシャルバックオフ)、Service Quotasでの引き上げ、クロスリージョン推論(複数のリージョンに処理を振り分ける)で対処する。
  • ネットワーク:VPCからはインターフェイス型のVPCエンドポイント(PrivateLink)で、インターネットを通らずに呼び出せる。
  • アクセス制御:IAMポリシーで、使えるモデルやAPIを制限する。

3. ユースケース#

  • 社内文書をもとに答えるチャットボット(ナレッジベースでRAG)
  • 問い合わせ・ログ・障害報告の要約や分類
  • 文章の生成・翻訳・画像の生成
  • 業務システムのAPIを呼び出して作業するAIエージェント

4. 料金の考え方#

方式内容
オンデマンド入力・出力のトークン数(モデルごとに単価が違う)に応じて課金
バッチ大量の依頼をまとめて非同期で処理する。オンデマンドより安い
プロビジョンドスループット一定の処理能力を時間単位で確保する。カスタマイズしたモデルの利用や、安定した大量の処理向け

ナレッジベース・ガードレール・エージェントには、それぞれの利用量に応じた料金が別にかかります。

5. 関連サービス#

  • AWS Lambda:Bedrockを呼び出すアプリの実行
  • Amazon S3:ナレッジベースの文書・ログの保存先
  • Amazon OpenSearch Service:ナレッジベースのベクトルの保存先
  • Amazon CloudWatch/AWS CloudTrail:呼び出しのログ・メトリクス・監査
  • VPCエンドポイント/Service Quotas
  • Kiro/AWS DevOps Agent:AWSが提供するAIエージェント

6. 試験・実務でのポイント#

  • 「複数の基盤モデルをサーバー管理なしで使う」→ Bedrock。社内文書を使った回答 → ナレッジベース(RAG)。
  • プロンプトと応答の内容を記録したい → モデル呼び出しのログを有効にする(CloudTrailには内容は残らない)。
  • ThrottlingException → 再試行・クォータの引き上げ・クロスリージョン推論。
  • 有害な出力やPIIの漏えいを防ぐ → ガードレール。インターネットを通さずに呼び出す → VPCエンドポイント。

7. まとめ#

  • Bedrockは、複数の企業の基盤モデルを共通のAPIで使えるフルマネージドの生成AIサービス。
  • 運用では、呼び出しのログ・メトリクス・クォータ・ネットワークの経路を押さえる。
