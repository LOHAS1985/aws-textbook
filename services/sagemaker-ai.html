Amazon SageMaker AI

機械学習用データの準備・特徴量管理からモデル開発までを支援するサービス

最終更新:2026-11-07

内容の確認:2026年11月7日

1. サービス概要#

Amazon SageMaker AI(旧Amazon SageMaker)は、機械学習モデルを構築・学習・デプロイするマネージドサービスです。データエンジニアの学習では、データ準備、データ品質の確認、特徴量の管理、機械学習パイプラインへのデータ提供を中心に押さえます。

Amazon SageMaker AIとAmazon SageMaker Unified Studioは同じものではありません。SageMaker AIはモデル開発を担うサービス、Unified Studioはデータ・分析・AIサービスをまとめる統合環境です。

2. 主な機能・特徴#

データ準備と特徴量#

  • Data Wrangler:データの取り込み・プロファイル・変換・品質レポートを支援する。現在のData Wrangler体験はSageMaker Canvasに統合されている。
  • Processing:データの前処理や評価をコンテナジョブとして実行する。
  • Feature Store:機械学習で再利用する特徴量を保存・共有する。
  • Pipelines:データ処理からモデル関連タスクまでのワークフローを定義する。

試験範囲との関係#

DEA-C01ではデータ準備やパイプライン統合、機械学習用データの品質・特徴量に関する考え方が関連します。モデルの学習や推論を実装すること自体は試験ガイドの対象外タスクとして示されています。データ処理の入力・出力・権限・コストを中心に学びます。

3. ユースケース#

  • 分析や機械学習の前にデータをプロファイル・変換する。
  • 前処理を再実行できるProcessingジョブとして実装する。
  • 複数のモデル開発者やジョブで共通の特徴量を利用する。
  • データ準備からML関連処理までをパイプライン化する。

4. 料金の考え方#

データ準備・処理・特徴量保存・ノートブック・モデル開発で使う計算資源やストレージなどに応じて料金が発生します。処理ジョブの実行時間、インスタンス、データ量、保存期間を見積もります。学習や推論の料金はデータ処理の料金と分けて確認します。

5. 関連サービス#

  • Amazon SageMaker Unified Studio:分析・AI開発の統合環境とプロジェクト
  • AWS Glue:ETLとData Catalog
  • Amazon Athena:SQLでのデータ準備・探索
  • Amazon Redshift:分析データソース
  • AWS Batch:コンテナ化されたバッチ処理
  • 関連する用語:データ品質、データガバナンス

6. 試験・実務でのポイント#

  • 機械学習向けデータのビジュアルな探索・変換・品質確認 → Data Wranglerの機能を押さえる。
  • 現在のData Wrangler体験はSageMaker Canvasに統合されている。
  • 再利用する特徴量の保存・共有 → Feature Store。
  • DEA-C01ではデータ処理・品質・統合を中心にし、モデル学習や推論の実装は対象外として区別する。

7. まとめ#

  • SageMaker AIは機械学習のライフサイクルを支援する。
  • 試験ではData Wrangler、Processing、Feature Storeなどデータ関連機能を中心に理解する。
  • Unified Studioは複数のデータ・分析・AIサービスをつなぐ別の統合環境。
