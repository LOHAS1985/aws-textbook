AWS Elastic Beanstalk

コードを渡すだけでアプリを簡単にデプロイ・運用できるPaaS

最終更新:2026-10-24

1. サービス概要#

AWS Elastic Beanstalkは、バックエンドアプリケーションを簡単にデプロイ・運用するためのPaaSです。開発者はアプリのコードを渡すだけで、AWSが実行環境を自動で構築してくれます。

2. 主な機能・特徴#

利用フロー#

  1. アプリケーションを作成
  2. デプロイ設定を定義
  3. アプリケーションバージョンを作成
  4. Environment(アプリを実行するAWS環境全体)へデプロイ
    • Beanstalkが内部でAWSリソースを操作する
    • EC2内にコードを配置する
  5. ヘルスチェック

デメリットは、ECS/EKSに比べて柔軟性が低いことです。

Beanstalkが自動で作るリソースには、EC2インスタンス、Auto Scalingグループ、ロードバランサーなどが含まれます。裏側ではCloudFormationが使われています。

代表的なデプロイ方式として、All at once(一斉)、Rolling、Rolling with additional batch、Immutable、Blue/Green(環境URLのスワップ)があります。

3. ユースケース#

  • インフラの知識が少ないチームで、Webアプリを素早く公開したい
  • Java・Python・Node.jsなどの一般的なWebアプリを、構成を作り込まずに運用したい

4. 料金の考え方#

Elastic Beanstalk自体は無料です。作成されたEC2・ロードバランサー・EBSなどのリソースに対して、それぞれの料金がかかります。

5. 関連サービス#

  • Amazon EC2:アプリが配置される実行環境
  • Elastic Load Balancing:環境のトラフィック分散
  • AWS CloudFormation:裏側で環境を構築する仕組み
  • Amazon ECS/Amazon EKS:より柔軟なコンテナ実行の選択肢

6. 試験・実務でのポイント#

  • 「インフラ管理を最小限にしてアプリをデプロイしたい」→ Elastic Beanstalk。
  • 細かな制御や柔軟性が必要なら ECS/EKS を選ぶ。
  • デプロイの単位は「アプリケーションバージョン」を「Environment」へ。

7. まとめ#

  • Elastic BeanstalkはコードだけでAWS環境を自動構築するPaaS。
  • 手軽さと引き換えに柔軟性は低い。
