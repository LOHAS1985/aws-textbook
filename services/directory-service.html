AWS Directory Service

クラウド上でActive Directoryによるユーザー管理・認証を提供

最終更新:2026-10-26

1. サービス概要#

AWS Directory Serviceは、クラウド上でユーザー管理・認証・権限管理を一元提供するサービスです。Active Directory(AD)を中心とした3種類があり、Windowsとの親和性が高いですが、Windows以外でも利用できます。

  • Managed Microsoft AD
  • Simple AD
  • AD Connector

2. 主な機能・特徴#

Managed Microsoft AD#

クラウド上で企業の社内AD環境を再現します。

  1. ユーザー/グループ管理
  2. 認証
    • ログイン(SSO)
    • ユーザー情報の取得:LDAP(認証の役割もあるが、情報基盤としての役割がメイン)。高速な検索が強みで、複数システムで同じユーザー情報(ユーザーID、パスワード、メールアドレス、所属グループ、権限情報など)を使い回せる。
  3. グループポリシー

Simple AD#

低コストで使える簡易版のActive Directory(機能制限版)です。小規模・検証用での利用が推奨されます。

AD Connector#

AWSと既存のActive Directoryを中継するだけのサービスです。オンプレミスのADとAWSを接続します(AWS側にディレクトリのデータは持ちません)。

種類ADの実体向いているケース
Managed Microsoft ADAWS上に本物のMicrosoft AD本格的なAD機能が必要、オンプレミスADとの信頼関係
Simple ADAWS上の簡易AD小規模・検証用、低コスト
AD Connectorオンプレミスの既存AD(AWSは中継のみ)既存ADのユーザーでAWSを使いたい

3. ユースケース#

  • EC2のWindowsサーバーやFSx for WindowsをADドメインに参加させる
  • 社内ADのアカウントでAWSマネジメントコンソールやWorkSpacesにログイン(AD Connector)

4. 料金の考え方#

ディレクトリの種類とサイズ(Small/Large、Standard/Enterprise)ごとの時間料金で課金されます。Simple ADが最も安価です。

5. 関連サービス#

  • Amazon FSx:FSx for WindowsのAD連携
  • Amazon EC2:Windowsインスタンスのドメイン参加
  • AWS IAM/AWS STS:ADユーザーへのAWS権限付与

6. 試験・実務でのポイント#

  • オンプレミスのADをそのまま使い、AWSにデータを置きたくない → AD Connector。
  • AWS上に本格的なADを構築 → Managed Microsoft AD。
  • 小規模・低コスト → Simple AD。

7. まとめ#

  • Directory ServiceはAD中心のユーザー管理・認証サービス。
  • 本格派=Managed Microsoft AD、簡易版=Simple AD、中継=AD Connector。
