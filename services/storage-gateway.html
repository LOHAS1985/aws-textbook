AWS Storage Gateway

オンプレミスのサーバーからAWSのストレージを、ファイル・ボリューム・テープとして使えるようにする

最終更新:2026-10-25

1. サービス概要#

AWS Storage Gatewayは、オンプレミスのサーバーから、AWSのストレージ(S3など)をいつものファイル共有・ディスク・テープ装置として使えるようにするハイブリッドストレージのサービスです。

オンプレミスにゲートウェイ(VMware・Hyper-V・KVM上の仮想マシン、またはハードウェアアプライアンス。EC2上にも置ける)を置きます。よく使うデータはゲートウェイのローカルにキャッシュして速く読み書きし、データ本体はAWSに保存します。

2. 主な機能・特徴#

ゲートウェイの種類#

種類オンプレミスからの見え方AWS側の保存先主な用途
S3ファイルゲートウェイNFS・SMBのファイル共有S3のオブジェクト(1ファイル=1オブジェクト)ファイルをS3に置き、AWS側の分析やバックアップにも使う
ボリュームゲートウェイiSCSIのブロックディスクS3(内部で管理)+EBSスナップショットサーバーのディスクのバックアップ・災害対策
テープゲートウェイiSCSIの仮想テープライブラリ(VTL)S3、アーカイブはS3 Glacier Flexible Retrieval/Deep Archive既存のバックアップソフトのテープ運用をそのままクラウドへ

FSx ファイルゲートウェイ(FSx for Windows File Serverへのアクセスをキャッシュする種類)は、新規の利用受付が終了しています。

ボリュームゲートウェイの2つのモード#

モードデータ本体の場所特徴
キャッシュ型AWS(よく使うデータだけローカルにキャッシュ)オンプレミスのディスク容量を減らせる
保管型オンプレミス(非同期でAWSにスナップショットとしてバックアップ)全データにローカルの速さでアクセスでき、AWSは災害対策用

運用のポイント#

  • S3ファイルゲートウェイで、ゲートウェイを経由せずにS3へ直接追加されたファイルは、すぐには見えない。キャッシュの更新(RefreshCache)を実行するか、自動更新の間隔を設定する。
  • キャッシュ用ディスクやアップロード用バッファの使用率は CloudWatch のメトリクスで監視する。不足すると書き込みが遅くなる。
  • ゲートウェイとAWSの通信は暗号化され、VPCエンドポイント経由にもできる。帯域幅の上限を時間帯ごとに設定できる。
  • ゲートウェイのソフトウェアの更新はメンテナンス時間に自動で適用される。
  • AWS Backupでボリュームゲートウェイのボリュームをバックアップできる。

DataSyncとの違い#

Storage Gatewayは、オンプレミスからAWSのストレージを使い続けるためのものです。データを一度にまとめて移行・転送するなら DataSync を使います。

3. ユースケース#

  • ファイルサーバーの容量不足を、S3を裏側にしたファイル共有で解消する
  • 物理テープとテープ装置の運用をやめ、既存のバックアップソフトのまま仮想テープへ移す
  • オンプレミスのサーバーのディスクをAWSにバックアップし、災害時はEBSボリュームとしてEC2で復元する

4. 料金の考え方#

AWS側に保存したデータ量(S3・EBSスナップショット・Glacierの料金)、ゲートウェイからAWSへの書き込み量、データの取り出し・転送量などに応じて課金されます。ゲートウェイの仮想マシン自体はオンプレミスの資源で動かします。

5. 関連サービス#

  • Amazon S3:データの保存先
  • Amazon EBS:ボリュームのスナップショットからの復元
  • AWS Backup:ボリュームのバックアップの管理
  • AWS DataSync:データの移行・転送
  • Amazon FSx:フルマネージドのファイルサーバー
  • Amazon CloudWatch:キャッシュなどの監視

6. 試験・実務でのポイント#

  • 「オンプレミスからS3をNFS/SMBで使う」→ S3ファイルゲートウェイ。
  • 「iSCSIのディスクをAWSにバックアップ」→ ボリュームゲートウェイ。「テープの置き換え」→ テープゲートウェイ。
  • S3に直接置いたファイルが共有に見えない → RefreshCache。
  • 移行はDataSync、オンプレミスから使い続けるならStorage Gateway。

7. まとめ#

  • Storage Gatewayは、オンプレミスからAWSのストレージを使うためのハイブリッドストレージ。
  • ファイル・ボリューム・テープの3種類のゲートウェイがある。
