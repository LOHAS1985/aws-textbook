AWS Compute Optimizer

機械学習でリソースの使用状況を分析し、最適な設定を推奨

最終更新:2026-10-26

1. サービス概要#

AWS Compute Optimizerは、機械学習を使ってリソースの使用状況を分析し、コスト削減・パフォーマンス向上につながる最適なリソース設定を推奨するサービスです。

2. 主な機能・特徴#

CloudWatchの過去のメトリクスを分析して推奨事項を提示します。

  • デフォルトでは無効。Organizations/アカウントで有効化が必要。
  • 分析期間:デフォルトは14日間(最大93日間)。

分析対象のリソース#

  • EC2インスタンス
  • Auto Scalingグループ
  • EBSボリューム
  • Lambda関数
  • ECS on Fargateサービス
  • RDS

推奨事項#

  • サイズが過大(Over-provisioned):コスト削減のためにダウンサイジングを推奨
  • サイズが過少(Under-provisioned):パフォーマンス改善のためにアップサイジングを推奨

EC2のメモリ使用率を分析に含めたい場合は、CloudWatchエージェントでメモリのメトリクスを送信しておく必要があります。

3. ユースケース#

  • 過剰なスペックのEC2インスタンスを見つけてダウンサイジング
  • Lambdaのメモリ設定の最適化
  • EBSボリュームのタイプ・サイズの見直し

4. 料金の考え方#

基本的な推奨は無料で利用できます。分析期間を延ばす「拡張インフラストラクチャメトリクス」は有料です。

5. 関連サービス#

  • Amazon CloudWatch:分析に使うメトリクス
  • Amazon EC2/Amazon EBS/AWS Lambda/Amazon ECS/Amazon RDS:分析対象
  • AWS Trusted Advisor:幅広い観点のチェック
  • AWS Organizations:組織全体での有効化

6. 試験・実務でのポイント#

  • 「機械学習で」「最適なインスタンスタイプ・サイズを推奨」→ Compute Optimizer。
  • デフォルトでは無効。使う前に有効化(オプトイン)が必要。
  • 分析期間はデフォルト14日、最大93日。
  • Cost Explorer・Budgets・CUR・Compute Optimizerの使い分け → コスト管理ツールの選び方。

7. まとめ#

  • Compute OptimizerはCloudWatchの履歴から、過大・過少なリソースを見つけて推奨する。

このサービスが登場する運用シナリオ#

  • EC2・EBSの性能不足を見つけて改善するCloudWatchのメトリクスとCompute Optimizerでボトルネックを特定し、止めずに性能を上げる
  • 負荷に応じて自動でスケールするWebシステムALBとAuto Scalingグループで、複数AZにまたがって台数を自動調整する
