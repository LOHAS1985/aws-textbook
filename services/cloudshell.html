AWS CloudShell

ブラウザから使える認証済みのシェル環境

1. サービス概要

AWS CloudShellは、AWSマネジメントコンソールからブラウザで直接使えるシェル環境です。ログイン中のユーザーの権限で認証済みの状態で起動するため、アクセスキーを設定せずにすぐAWS CLIを使えます。

2. 主な機能・特徴

  • AWS CLI、Python、Node.js、gitなどがあらかじめインストールされている。
  • コンソールにサインインしたIAMユーザー/ロールの権限で動作する。
  • ホームディレクトリに1GBの永続ストレージがあり、リージョンごとに保持される。
  • VPC環境で起動して、プライベートリソースにアクセスすることもできる。

3. ユースケース

  • 手元のPCにCLIを入れずに、AWS CLIでちょっとした操作や確認をしたい
  • アクセスキーを発行せずに安全にコマンドを実行したい
  • 学習・検証での一時的な作業

4. 料金の考え方

CloudShell自体は追加料金なしで利用できます。CloudShellから操作したAWSリソースの料金は通常どおりかかります。

5. 関連サービス

  • AWS IAM:CloudShellの実行権限
  • AWS SDK:プログラムからのAWS操作
  • AWS Systems Manager:Session ManagerでのEC2への接続

6. 試験・実務でのポイント

  • ブラウザから認証済みでAWS CLIを使う → CloudShell。
  • EC2のOSにログインする → Session Manager(CloudShellはEC2への接続サービスではない)。

7. まとめ

  • CloudShellはコンソールから使える、認証済み・ツール入りのシェル環境。
