AWS Amplify

フロントエンド開発者がAWSのバックエンドを簡単に使えるサービス群

最終更新:2026-10-24

1. サービス概要#

AWS Amplifyは、フロントエンド開発者がAWSのバックエンドを簡単に利用できるようにするサービス群です。

2. 主な機能・特徴#

  • Amplify Hosting:静的Webサイトのホスティング。Git連携によるCI/CDを実現する。
  • Authentication:認証機能を簡単に追加できる(内部ではCognitoを使用)。

ほかにも、API(AppSync/API Gateway)、データ保存(DynamoDB)、ファイルストレージ(S3)などのバックエンドを、Amplifyのライブラリやコマンドから簡単に追加できます。React・Vue・Next.jsなどのフレームワークや、iOS/Androidアプリに対応しています。

3. ユースケース#

  • GitHubにプッシュするだけで自動デプロイされるWebサイト
  • Webアプリにログイン機能(サインアップ・サインイン)を素早く追加
  • 小規模チームでのフルスタックアプリ開発

4. 料金の考え方#

Amplify Hostingは、ビルド時間・保存容量・配信データ量で課金されます。Cognitoなど裏側で使うサービスは、それぞれの料金がかかります。

5. 関連サービス#

  • Amazon Cognito:Authenticationの実体
  • AWS AppSync:GraphQL API
  • Amazon S3/Amazon CloudFront:静的サイトの配信
  • AWS CodePipeline:汎用的なCI/CD

6. 試験・実務でのポイント#

  • フロントエンドのホスティング+Git連携のCI/CD → Amplify Hosting。
  • Amplifyの認証は内部でCognitoを使っている。

7. まとめ#

  • Amplifyはフロントエンド開発者向けにホスティングと認証などを簡単に提供する。
